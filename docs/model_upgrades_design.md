## 📐 总体架构（升级后目标形态）

```
                    ┌─────────────────────────────┐
                    │  升级4: 情绪周期门控(日频)      │ ← 只决定"今天能不能开仓"
                    └──────────────┬──────────────┘
                                   ▼
                    ┌─────────────────────────────┐
                    │  升级1: 波动率门控(个股)        │ ← 只决定"这只票现在敢不敢碰"
                    └──────────────┬──────────────┘
                                   ▼
                    ┌─────────────────────────────┐
                    │  升级2: IVU 成交量不确定性因子   │ ← 特征层融合
                    │  + 现有33特征 + L2级特征       │
                    └──────────────┬──────────────┘
                                   ▼
                    ┌─────────────────────────────┐
                    │  升级5: 排序学习(相对强弱打分)   │ ← 模型层升级(替代3分类)
                    └──────────────┬──────────────┘

                    ┌─────────────────────────────┐

```

**层级关系**: 升级4(日频门控) → 升级1(个股门控) → 升级2(特征) → 升级5(模型) → 升级3(执行)。

# 升级1: 波动率门控（Volatility Gate）
# ══════════════════════════════════════════════

## 1.1 动机（回测实证）
- 现有回测: 317样本 × (止盈/止损矩阵) = 所有组合负期望；纯持有30日 +7.69%
- 根因: 高波动股票的正常波动(-3%~-6%)就触发止损，杀掉55%最终赢家
- arXiv 2606.09478: 收益可预测性主要存在于**低波动率区间**

## 1.2 因子定义
```
vol20 = 20日日均振幅 = mean[(high - low) / close * 100]   # 每只股票每日计算
gate  = vol20 分位分组（全市场截面分位）
  - Q1 低波动 (< 25%分位)
  - Q2 中低波动 (25-50%)
  - Q3 中高波动 (50-75%)
  - Q4 高波动 (> 75%)
```

## 1.3 门控规则（候选，需回测选定）
```
方案A(保守): 仅 vol20 处于 Q1/Q2 才允许开仓
方案B(中性): Q1/Q2/Q3 允许，Q4 禁开仓
方案C(自适应): 开仓时用 vol20 动态设定止损 = -2.5 × vol20（宽止损匹配波动率）
```

## 1.4 与现有模型融合
- 位置: paper_trading_signals.py 选股前 + trade_executor.py 开仓前双重校验
- 实现: `gate_check(symbol) -> bool`，读取 `vol20` 缓存（由数据管线每日更新）

## 1.5 数据需求
- 现有: kline_all.parquet（有 high/low/close）→ 直接可算
- 无新数据源

## 1.6 回测验证方法
```
用 backtest_tp_sl_matrix.py 改造:
  对317样本按 vol20 分位分组
  分别统计: Q1/Q2/Q3/Q4 的持有10日/20日收益 + 止盈止损组合期望
  预期: Q1/Q2 期望为正且显著 > Q4
验收: 门控后整体期望 > 无门控期望（+2.68%@10日 → 目标 >4%）
```

## 1.7 实现步骤
1. 写 `backtest_vol_gate.py` 验证分位分组收益差异
2. 选定门控方案（A/B/C）
3. 在 features_v2 增加 vol20 特征 + paper_trading_signals 加 gate
4. 模拟盘 A/B 一周

# 升级2: IVU 成交量不确定性因子（开盘半小时）
# ══════════════════════════════════════════════

## 2.1 动机（论文依据）
- MDPI 2026 (中国A股): IVU = 开盘半小时成交量 / 前7个区间总量
  - IVU > 0.476 → 低不确定性；≤ 0.476 → 高不确定性
  - 高开量+高不确定性 → 初始收益预测力最强（XGBoost OOS 71.43%）
  - 策略7年 Sharpe 3.02

## 2.2 因子定义（适配5分钟K线）
```
IVU_t = V(开盘30分钟) / V(前7个30分钟区间)     # 论文原始定义
    简化版(适配我们5分钟数据):
    当日9:30-10:00共6根5分钟bar的成交量之和
IVU = ─────────────────────────────────────────
      前7个交易日同时间段(9:30-10:00)平均成交量
```
- 附加: `open_vol_ratio` = 今日开盘30分钟量 / 昨日全天量
- 附加: `open_price_gap` = (今开 - 昨收) / 昨收 （配合判断高低开）

## 2.3 融合方式
- **特征层**: 3个新特征加入 XGBoost 特征集（原33 → 36）
- **状态层**: IVU 高低两态，模型可在两个状态分别训练或加状态交互特征
- **风控层**: 高IVU（高不确定性）+ 高开盘量 → 允许加仓；低IVU → 降低仓位

## 2.4 数据需求
- 5分钟K线: QMT/mootdx（现有 qmt_model_02 已能拉5m）
- **新增**: 需要每只股票前7日5分钟数据（mootdx 最多7天，够用）
- 需持久化: `data/ivu_cache.json` {symbol: {date: {ivu, open_vol_ratio}}}

## 2.5 回测验证方法
```
用本地 5分钟K线(mootdx 7天) 或 QMT 导出数据:
  样本: 300只活跃股 × 7天 × 48根
  构造 IVU + 未来3根涨跌幅标签
  对比: 含IVU特征的模型 vs 不含，OOS AUC/准确率
  分组: 高IVU组 vs 低IVU组的预测准确率差异
验收: 高IVU组准确率 ≥ 65%（论文称71%）
```

## 2.6 实现步骤
1. `build_ivu_cache.py` 每日收盘后计算并缓存
2. features_v2 增加 IVU 特征（3个）
3. 重训 main_force_v3 模型
4. 回测对比 v2 vs v3

# 升级3: 5分钟均线动态离场（替代固定%止损）
# ══════════════════════════════════════════════

## 3.1 动机
- 业界共识（头条/东财多篇）: 固定%止损反应慢、洗盘误杀
- 我们回测实证: 固定止损杀55%最终赢家
- 5分钟均线 = 短线资金强弱分水岭

## 3.2 规则定义
```
持有条件: 收盘价 ≥ MA5(5分钟线) 且 MA5 斜率向上
减仓信号: 收盘价 < MA5 且 MA5 拐头向下（连续2根确认）
清仓信号: 高位(当日涨幅>5%)放量(量比>2)跌破 MA5 → 无条件清
```
- MA5 = 最近5根5分钟K线收盘均值（≈25分钟短线趋势）
- 补充: 结合升级1的 vol20 → 止损下限 = max(-2.5×vol20, -8%) 兜底防黑天鹅

## 3.3 融合方式
- 位置: trade_executor.py 卖出逻辑，**替代**现有"峰值回撤6%"趋势跟踪
- 保留: 跌停(-9.7%) / 超期15天 兜底
- 开关: `EXIT_MODE = "ma5" | "trail" | "hybrid"`

## 3.4 数据需求
- 5分钟K线实时（QMT get_market_data_ex period='5m'，现有能力）
- 盘中每5分钟触发检查（现有 executor cron 每10分钟，可加密到5分钟）

## 3.5 回测验证方法
```
模拟: 买入后按MA5规则离场 vs 固定-6%止损 vs 峰值回撤6%
指标: 期望值/胜率/最大回撤/平均持有天数
验收: MA5离场期望 > 固定止损期望（当前-3.23%）且 > 趋势跟踪
```

## 3.6 实现步骤
1. `backtest_ma5_exit.py` 用5分钟数据回测三种离场
2. trade_executor 增加 exit_mode 配置
3. 模拟盘验证一周

# 升级4: 情绪周期门控（日频，决定可否开仓）
# ══════════════════════════════════════════════

## 4.1 动机
- 短线掘金体系: 情绪周期四阶段(冰点/回暖/高潮/退潮)，仅回暖期出手胜率最高
- 我们目前无市场情绪维度，熊市/退潮期也强行选股

## 4.2 情绪指标定义（开盘30分钟可算）
```
指标1: 涨停家数 / 跌停家数 比值（市场攻击性）
指标2: 昨日涨停股今日溢价率均值（接力意愿）
指标3: 最高连板高度（情绪温度）
指标4: 上涨家数占比（宽度）

情绪阶段判定:
  冰点: 涨停<20家 或 连板高度≤2
  回暖: 涨停20-50家 且 溢价率>0 且 连板高度3-4
  高潮: 涨停>80家 且 连板高度≥6
  退潮: 涨停从高潮回落>30% 或 溢价率转负
```

## 4.3 门控规则
```
开仓许可: 情绪 ∈ {回暖}  → 正常仓位
         情绪 = 冰点/退潮 → 空仓或半仓防守
         情绪 = 高潮     → 减半仓（防退潮）
```

## 4.4 数据需求
- 涨停/跌停/连板数据: 现有系统有（daily_recommend/涨停池?需确认）
- 若缺: 可用东财涨停板池API 或 自算(日涨幅≥9.5%)

## 4.5 回测验证
```
对317样本按"当日情绪阶段"分组，统计各组收益
验收: 回暖期样本期望显著 > 冰点/退潮期
```

## 4.6 实现步骤
1. `market_sentiment.py` 每日09:30-10:00 计算情绪
2. paper_trading_signals 加情绪门控
3. 回测验证 → 上线

# 升级5: 排序学习（Learning-to-Rank）替代3分类
# ══════════════════════════════════════════════

## 5.1 动机
- 清华论文: 预测绝对收益率 → 改为预测**截面相对排序**，效果显著提升
- 我们的3分类(买卖持)是绝对概率，忽略"相对强弱"
- 相对排序对市场整体涨跌不敏感（牛市熊市都适用）

## 5.2 模型设计
```
输入: 同一时刻全市场股票的特征矩阵 (N × 36维)
标签: 未来3根5分钟K线的涨跌幅 → 全市场分位排名 (0-100)
模型: XGBoost rank:objective (LambdaRank) 或
      分类改造: 标签 = 是否进入Top10%分位 (二元)
输出: 每只股票"相对强弱分" → 取Top2买入
```

## 5.3 融合方式
- 替代现有"买/持/卖"3分类预测 → 输出连续强弱分
- 买卖信号: 强弱分 > 阈值 → 买；跌破均线 → 卖（接升级3）
- 全市场打分每日一次（日频） + 盘中滚动更新

## 5.4 数据需求
- 全市场5分钟K线（现有kline_all.parquet只有日线）
- **新增**: 需全市场5分钟数据 → QMT全量导出 或 逐日累积
- 备选: 先用Top300活跃股做小规模验证

## 5.5 回测验证
```
截面排序 IC: 每日"预测分位 vs 实际收益分位"的秩相关(Spearman)
验收: 平均IC > 0.03 且 Top10%组未来收益显著 > Bottom10%组
```

## 5.6 实现步骤
1. 全市场5分钟数据累积脚本
2. `train_rank_model.py` 训练LambdaRank
3. 回测IC验证 → 替换现有打分 → 模拟盘

## 📌 升级2 实施结果（2026-08-01 03:15 实测）

### IVU 因子验证结论（200 活跃股 × 5分钟数据）
| 特征集 | AUC | 结论 |
|--------|------|------|
| 33 原始 | 0.7198 | 基线 |
| **33 + IVU** | **0.7610** | ✅ 单独加有效 (+4.1%) |
| 33 + open_gap | 0.7308 | 略升 |
| 33 + IVU + gap | 0.6923 | ❌ 共线稀释, 不加 |

### 重大发现: open_gap（开盘缺口）单独预测力
| 开盘缺口 | 未来3根收益 | 方向准确率 |
|---------|-----------|-----------|
| 深低开 (<-1%) | +0.43% | **70.7%** |
| 微低开 | +0.30% | 59.0% |
| 微高开 | -0.25% | 18.3% |
| 高开 (>+1%) | -1.63% | **4.0%** |

**规律**: 低开→涨（主力吸筹）, 高开→跌（主力出货）, 相关性 -0.64。
高开1%+ 未来3根下跌概率 96%！

### 最终方案
- **模型特征**: 33原始 + IVU（34特征, AUC 0.7610）
- **open_gap 作风控规则**（不进模型避免共线）: 高开>1% 禁买, 低开<-1% 优先买
- **数据要点**: mootdx 5分钟 bar time_idx 从 575 开始(9:35第一根), 开盘30分钟=575-600, after=605+

## 📌 硬删除 vs 软因子 架构原则（2026-08-01 11:18 用户指示）

**用户原则**: 模型里不要太多硬塞门控。只有"事实性负面"才硬删除：
1. ✅ ST/*ST 股票（退市风险）
2. ✅ 业绩亏损股（net_profit<0, 全市场1252只占25%）
3. ✅ 近期利空消息（LLM情绪分<-0.01）

**其他一律软因子（打分/权重）**, 不一票否决。

**实现**:
- `hard_filter.py`: 三类硬删除模块 (is_st / is_loss_maker / has_negative_news)
  - 数据: data/fundamental_data.json (4996只, net_profit字段)
  - ST: 源端 data_fetcher.py 已过滤(正则 \*?ST), hard_filter 兜底
  - 利空: output/news_sentiment.json LLM情绪分
- v2 系统升级 v2.2: hard_filter(硬删) + open_gap 降级为打分(低开+0.05/高开5%+-0.08)
- 单元测试通过: 万科A(亏损)删, *ST国农(ST)删, 平安/宁德保留

**open_gap 数据修正记录（184万样本验证）**:
- 单日5分钟结论(高开跌96%/相关性-0.64)是当日行情的假象, 已收回
- 大样本真相: 低开1-3%当日+0.39%胜率53% > 高开5%+当日-0.83%胜率36%
- 但高开5%+涨停率47.6% → 不能一票否决, 降级为打分
- 大幅低开(<-6%)当日-0.37%: 不是反弹是继续跌(修正用户第4条观察)
- 多因子: 近10日涨停次数 + 成交额分位 显著增强(高开1-3%: 低额-0.49% vs 高额+0.66%)
