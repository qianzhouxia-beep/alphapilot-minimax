## 1. 因子速览（要融合的东西）

**弱市超跌反包**（T+1 短反抽脉冲）：

| 项 | 内容 |
|---|---|
| 定义 | 近5日无跌停 + 连跌≥3天 + 长上影(high距close>50%区间) + 120日低位(pos120≤0.2) + **大盘3日累计跌** |
| 交易 | T **尾盘买** → T+1 **收盘卖** |
| 样本内 | 胜率 60.4%、+0.61%（n=22,979，上影Top40%口径）；61.0%/+0.65%（上影≥0.5 口径，本探测复现 n=6,207） |
| 大盘开关 | 3日跌 60.4% vs 3日涨 46.3%（负期望 → 强开关，**只在弱市开**） |
| 特性 | T+1 短脉冲，T+5 无持续性；个股中期方向无筛选力（**下跌通道反而是主战场**，98% 样本集中在低位深度超跌） |
| 关键脆弱点 | **edge 只在 T 尾盘买成立**：T+1 开盘买→收盘卖 edge 归零（−0.05%） |

## 2. 现有 P2 选股链（融合的落点在哪）

```
05:00  alphapilot_pipeline_v3.py + V25 106维打分 → 漏斗池 (N 只)
09:35  live_momentum_scanner.py 双路径重排：
         pool≥100 → 池内重排；pool<100 → 涨幅Top~1000资金轨（与05:00池可零重叠，有意设计）
09:35  morning_live_fund_select.py：资金门(money_flow_gate) + 研报门 + 板块软层
         → money_flow_pass 优先 + score 降序 → Top2（候选池 Top10）
09:36  export_qmt_scores.py 保序导出 {date}.candidates.json（QMT/通达信只读这份）
09:38  build_score_top10.py 三路融合 = 网页展示榜，不是下单顺序
```

- 池 = **资金闸门(gated 16~49只) + score**；Top2 T+1 已隐含龙头偏好。
- P2 低开组 T+1 +1.56% / 胜率61.3% —— 与超跌因子同方向（超跌/低位）但**口径不同**：P2 是 9:35 选股（T 日选出、T+1 买），超跌因子是 **T 尾盘买、T+1 卖**。
- 选股 vs 买卖模型分离原则（`knowledge/strategies/selection_vs_execution.md`）：改选股不动交易端、改买卖规则才动 QMT/TDX。
- 生产文件只在 `production_strategies/` 内改，根目录同名文件冻结。

## 3. 四条融合路径对比

| | A. 候选池生成门（旁支池） | B. 排序加分项 | **C. 旁路独立小仓位（推荐）** | D. P2 已选票择时增强 |
|---|---|---|---|---|
| 机制 | 超跌条件做 gated pool 并列旁支闸门 | score + 超跌加分，抬 Top2 | 独立 scanner（14:50 as-of）→ 尾盘买/T+1卖，与 P2 并行 | P2 选出的票若恰在超跌状态，尾盘买替代次日 9:36 买 |
| 时间尺度 | 09:35 判定 vs 信号 14:57 成形 | 09:35 判定 | T 尾盘买 / T+1 卖 | T+1 尾盘 |
| 与 P2 池重叠（探测） | 0%（互斥） | 加分无对象（0% 命中） | 0%（正交，天然不冲突） | **0/71（当前样本无适用对象）** |
| 是否破坏 P2 现有逻辑 | 并列不影响，但原样无 edge | 会扰动排序 | 完全不触碰 P2 链路 | 改 P2 买入时点 |
| 关键结论 | ⚠️ 原样不可行：09:35 出池无筛选力（预筛池 n=57,035，52.6%/+0.25%），edge 靠 14:57 成形 → A 的有效形态 = C | ❌ 否决：走 08-22/08-15 老路，必 0 增量 | ✅ 唯一同时满足「时间尺度匹配 + 零重叠 + 不改 P2」 | ❌ 当前样本不可用（0 命中） |

## 4. 逐路径评估

### 路径 A：候选池生成门（旁支池/闸门）

- **重叠度（探测 Q1）**：生产 gated pool 71 票 × 15 天中，09:35 可见已超跌 1 票（1.4%），当日尾盘成形完整超跌 **0 票**，Top2 **0/11**，反向（全市场 85 个超跌信号落在池内）**0**。→ 超跌池与 P2 池**结构性互斥**，旁支池不会破坏现有池逻辑（因为根本不重叠）。
- **结构性原因**：P2 池 = 资金闸门 + score，选的是**当日强势票**（池内 75% 为上涨日，中位 +4.07%）；而超跌因子要求连跌≥3——当日涨 4% 的票不可能连跌 3 天。**天然正交，不是参数巧合。**
- **致命问题（探测 Q3）**：09:35 成形旁支池时，当日上影/当日连跌尚未发生，只能拿到 T-1 预筛——全市场预筛池 n=57,035（无筛选力，T 开盘买 T+1 卖 52.6%/+0.25%，远低于尾盘 61%/+0.65%）。edge 只在 14:57 用**当日数据**成形时存在。
- **变形 A'**：09:35 只判定「今天是否 arm 超跌旁路」（大盘3日跌开关，T-1 数据可算），14:50-14:57 用当日 as-of 数据实际选股。**这个变形就是路径 C 的执行方式**——A 的可行形态与 C 重合。
- **历史教训**：08-22 同花顺 T-1 涨停/热股/龙虎榜加进 P2 排序被否决——拟议旁支分 14 天换人 0 天（池内选不出）、硬剔除昨日涨停误杀美利云/宝鼎科技两只次日 +10% 票。本探测给出同构证据：P2 池内根本没有超跌票，任何"池内旁支"都是空转。

### 路径 B：排序加分项（score + 超跌加分）

- **为什么必走 08-22/08-15 老路（0 增量）**：
  1. 加分只在**被选票内部换排序**，而超跌票命中 P2 池 = **0**，加分点空转 → 必然 0 增量；
  2. 若要加分成形（把池外超跌票拉进池），那已经是扩池/旁路（路径 A/C），不是"加分"；
  3. 08-22 实证：组内"昨涨停/龙虎榜偏弱"是真的，但**分数已经把它们排后面**，加分是重复劳动；
  4. 08-15 实证：P2 Top2 加"龙头优先/资金量加成"，资金量加成**反指 −74pp**；唯一正增益（同板块去重）在生产大池口径复验后默认关闭。
- **历史教训金句**："改 score 排序/加分项是最容易出 0 增量或反指的路；因子的正确入口往往是候选池生成门或旁路。"（08-15 落地复盘）
- **结论**：直接否决。若要观察，只能走 shadow 模式（`hithink_p2_side` 同款：只标注、不改 score、默认关）。

### 路径 C：旁路独立小仓位（推荐）

- **机制**：
  - 选股侧（服务器）：新增独立尾盘 scanner（复用 `live_momentum_scanner` 模式），14:50 以当日 as-of 数据成形超跌组合（连跌≥3 + 上影 + pos120≤0.2 + 无跌停5日 + 大盘3日跌开关），产出 `{date}.reversal_candidates.json`。
  - 大盘开关：**直接复用 `market_env_gate.py` 的 `ret_3d` + `build_env_asof`**（已 as-of、无未来函数，探测 Q2 确认生产可算）。
  - 买卖侧（QMT/TDX）：14:57 尾盘集合竞价/市价买入（日限 N 只，如 1~2），T+1 14:50-14:57 卖出（收盘卖需提前下单）。
  - 资金：独立小仓位（建议 ≤20% 或与 P2 的 expo 独立核算），**不挤占 P2 仓位**；跟随 P2 的 expo 开关（expo=0 时旁路也关）。
  - 影子先行：第一周只写 jsonl 不对单，与 P2 实盘并存观察。
- **探测支撑**：
  - 正交性：与 P2 池 0 重叠 → 组合层面互补（P2 强势 + 超跌反抽），无内耗；
  - 候选充足：全市场组合候选/日 ≈ 21（上影≥0.5 口径）/ 62（Top40% 口径）→ 日选 1~2 只绰绰有余；
  - edge 可复现：本探测 61.0%/+0.65%（上影≥0.5，n=6,207）与卡片 60.4%/+0.61%（Top40%，n=22,979）一致；
  - 大盘开关 as-of：`market_env_gate` 现成。
- **风险（详见第 6 节）**：T+1 收盘卖滑点、T+1 跌停卖不出、样本内选择偏置、开关口径漂移、QMT 尾盘单支持待验证。

### 路径 D：P2 已选票的择时增强

- **探测 Q1 的路径 D 专项**：池内票在 **T+1 尾盘成形完整超跌 = 0/71**（Top40% 口径同 0）。当前生产口径下无适用对象。
- **结构原因**：P2 选强势票，即便后续跌深也落入 P2 的止损/卖出规则（Plan C 分级止损），不构成"尾盘择时增强"对象。
- **结论**：当前不可用。若未来弱市导致 P2 池结构变化（如池内票普遍转弱），重测该重叠度后再议。

## 5. 可行性探测的三个答案

探测脚本：`bt_research/bt_reversal_overlap_probe.py`（面板 2025-01~2026-08-24 + 生产 gated pool 存档 15 个有效交易日 + `market_env_gate` 同源指数数据）。

**Q1：P2 池中"连跌≥3+低位"占多少？超跌因子与 P2 池是否天然正交？**

> **天然正交，近乎零重叠。** gated pool 71 票：09:35 可见已超跌 1.4%、当日成形完整超跌 0%、Top2 0/11、反向 0/85。结构性原因：P2 池 = 资金闸门+score 选当日强势票（池内 75% 上涨日、中位 +4.07%），与"连跌≥3"定义互斥。**不是重叠加分，是完全不重叠。**

**Q2：大盘3日跌开关在生产管线里能否 as-of 计算？**

> **能。** 生产 `market_env_gate.py` 已实现：东财指数 K 线 → `ret_3d`（3 日累计涨跌幅）+ `build_env_asof(asof)`（as-of 过滤、无未来函数），本地缓存 `data/index_klines_hist.json`（生产实时拉取，本地副本截至 08-07）。09:35 用 T-1 收盘判定，14:57 用当日盘中价近似判定。
> ⚠️ **口径校准项**：回测用等权全市场平均涨幅，生产天然用上证指数——探测中两口径开关方向 4/6 一致（2 天不一致）。落地前必须选定口径并在全样本重跑开关分组。

**Q3：09:35 打分 vs T 尾盘买，时间错配是否天然排除 A 路径？**

> **是，直接排除"09:35 选股买入"的任何 A 路径变体。** 全样本证据（探测 Q3）：
> - 信号 T 收盘成形 → **T 尾盘买** T+1 收盘卖：**61.0% / +0.65%**（edge）；
> - 同信号 → T+1 **开盘**买 T+1 收盘卖：**53.2% / +0.20%**（edge 损失 2/3，卡片 Top40% 口径下甚至归零 −0.05%）；
> - 09:35 唯一可见的 T-1 预筛 → T 开盘买 T+1 收盘卖：**52.6% / +0.25%**，且全市场 n=57,035 无筛选力。
>
> 时间错配是**结构性**的：edge 由"当日完整信息（含当日上影/当日连跌/当日大盘）在尾盘成形"产生，09:35 缺这三块信息。A 路径若想存活，只能退化为 C（09:35 只 arm 开关，14:57 实际选股买）。

## 6. 推荐路径与理由

**推荐：路径 C（旁路独立小仓位）**，理由：

1. **时间尺度天然解耦**：T 尾盘买/T+1 卖 vs P2 的 9:35 选/T+1~T+5 持，两套信号、两套执行、两套持仓，不需要动 P2 任何链路（不改打分、不改池、不改排序）——符合"选股 vs 买卖模型分离"原则，也符合 08-15 复盘定下的"因子正确入口 = 候选池生成门或旁路"。
2. **探测证明与 P2 池零重叠**：组合层面正交，不抢占 P2 仓位、不引入与 P2 信号的排序冲突。
3. **两处现成基建可复用**：大盘开关 `market_env_gate`（as-of 现成）+ scanner 模式 `live_momentum_scanner`（独立 scanner 先例，且"与主池零重叠是有意设计"已有 08-25 定案）。
4. **风险边界清晰**：小仓位 + 影子先行，最坏情况是浪费一个小仓位，不伤 P2 主链。

**落地顺序建议**（先验证后上线）：

```
① 影子周（只写 {date}.reversal_candidates.json + shadow jsonl，不对单）
② QMT 模拟盘 dryrun 尾盘单（14:57 买入 / T+1 14:52 卖出）2 周
③ 滑点/成本敏感性 + 大盘开关口径定标 + 样本外（详见验证清单）
④ 通过后小仓位实盘（≤20%），继续记录并与 P2 独立核算
```

## 7. 落地所需验证清单（未做即不可上线）

| # | 验证项 | 方法/数据 | 通过标准 |
|---|---|---|---|
| 1 | **滑点/成本敏感性** | 尾盘买/收盘卖加 0.05/0.10/0.20% 单边成本；对比"尾盘买/次日开盘卖" | 0.1% 单边下仍 ≥55% 胜率 |
| 2 | **与 P2 池叠加增量** | 全样本 P2 池(资金门+score 代理) ∪ 超跌组合 vs 各自单独；因零重叠预期联合≈两者之和，确认无内耗 | 联合 ≥ max(单组) |
| 3 | **样本外确认** | 面板外年份（如 2024）或滚动 OOS；**purged/embargoed CV**（参考 08-24 右尾教训：purged 后优势砍半） | OOS 胜率 ≥55% 且方向一致 |
| 4 | **大盘开关口径定标** | 等权全市场 vs 上证指数 mkt3 分组全样本复跑（探测仅 4/6 天一致） | 选定口径后开关分组与卡片一致（60% vs 46%） |
| 5 | **QMT 尾盘执行** | 模拟盘 14:57 集合竞价/市价买入、T+1 14:52 卖出，含收盘单延迟 | 2 周成交率 ≥90%、平均滑点 <0.1% |
| 6 | **ST/退市/跌停硬过滤** | 复用 08-25 *ST威领 事故后的全链路 ST 硬过滤；叠加 T+1 跌停卖不出的熔断（如 T+1 开盘 -3% 即卖） | 0 ST 入池 |
| 7 | **信号时点敏感性** | 14:50 vs 14:57 成形（尾盘最后 7 分钟数据变化） | 两时点组合差异 <0.1pp |
| 8 | **候选池流动性** | 组合候选的日成交额分位（防 2000 万以下无法成交） | 中位成交额 ≥5000 万 |

## 8. 风险清单（讲透）

1. **样本内选择偏置**（最高风险）：30 个 as-of 因子挑出的组合，双年稳健（18 月 15 月胜率≥50%）但最差 2026-01/05 月接近 47%；必须 purged/embargo CV + 样本外，**未通过不上线**。
2. **T+1 收盘卖的执行滑点**：edge 全部来自 T+1 收盘卖，尾盘流动性差、收盘单延迟都会侵蚀；需验证清单 #1/#5。
3. **T+1 跌停卖不出**：回测"无跌停5日"只排除了 T-5..T-1，T+1 当天跌停仍可能锁死；需熔断退出。
4. **大盘开关口径漂移**：等权 vs 指数 4/6 一致，若直接上指数口径可能改变开关分组；必须定标重跑。
5. **策略利用率低是设计内**：开关只在弱市 arm（存档窗口 4/15 天），大多数日子空转；小仓位下年化次数有限，勿过度预期。
6. **QMT 尾盘单能力依赖**：14:57 集合竞价下单、T+1 尾盘卖出是否被 QMT/券商支持（尤其模拟盘），需 dryrun 实证；不通则退化为 14:52 限价单。
7. **与轨道 B 的交互**：轨道 B 是交易端 09:25-09:35 竞价选股（独立于服务器选股），与超跌旁路时间窗口不同（B 早盘、超跌尾盘）不直接冲突，但**资金分配需显式声明**，避免两路共用预算导致某日超仓。
8. **与 P2 的 expo 联动**：expo=0（核弹日）时超跌旁路是否同关？建议跟随，避免弱市对赌（但注意：大盘 3 日跌开关本身就是"弱市才买"，与 expo 语义需校准——这正是验证清单 #4 的延伸）。

## 9. 关键结论一句话

**超跌反包因子与 P2 池在结构上零重叠（不是重叠加分，是完全不重叠），因此 A/B/D 三条路在当前生产口径下要么空转、要么 0 增量、要么无对象；唯一成立的是 C——把超跌因子作为独立的小仓位尾盘旁路，与 P2 并行，不动 P2 任何链路。落地上线的唯一前提是先过滑点/成本、样本外与 QMT 尾盘执行三项验证。**
