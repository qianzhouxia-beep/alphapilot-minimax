结果：

口径：开盘前已知（资金日严格 < D）。交易：T+0 开盘 → T+1 收盘。  
样本：沪深、昨收 ≥ 3 元、昨日成交额 ≥ 5000 万、昨日涨幅 < 9.5%。  
390 个交易日 / 150 万行；制度检验用 2026-04-01 切开（训 297 / 测 93）。  
制度切换再用 377 日、滞后 2 日的 20 日 RankIC 走步。

## 结论（先看这个）

**没有发现一条能稳定打败「东财主力净额」的新静态资金字段。**  
质量比、加速、价量背离、强度、行业份额，在全样本上都翻不过 `main_net_5d`，而且多数跟行情制度一起变号。

**真正多出来的、能同时抬收益和胜率的，是资金因子的符号制度：**

- 近 20 日 `RankIC(5日主力净额, T+1)` > 0 → 做资金**延续**（5 日净额截面前 10%）
- 否则 → 做资金**吸筹**（昨日流入 且 5 日涨幅 ≤ 0）
- 制度用已完成的 T+1（滞后 2 日）计算，开盘前可算，无未来函数

这不是新数据源，是别人最容易做错的地方：大多数量化把「主力净流入」当成永远为正的 Alpha。

## 静态因子：训 / 测翻号

| 因子 | 训练集 RankIC | 测试集 RankIC | 说明 |
|------|---------------|---------------|------|
| 5 日涨幅 | −0.036 | **+0.039** | 动量本身在翻 |
| 5 日主力净额 / 其截面排名 | −0.021 | **+0.037** | 已在 106 维里 |
| 昨日主力净额 | −0.006 | +0.025 | 已在 106 维里 |
| 连续流入天数 | −0.008 | +0.019 | 影子已用 consec≥2 |
| 流入质量 sum/\|sum\| | −0.012 | +0.017 | 弱于 5 日净额 |
| 行业内排名 | −0.005 | +0.011 | 不独立 |

测试集里「已经大涨 >8%」T+1 最好（+0.50%），训练集里最差（−0.12%）。  
「价跌但有流入」训练集胜率 51.4%、+6bp；测试集胜率 45.0%、−13bp。  
**同一条资金规则，换一段行情就反着赚。**

唯一没有翻号的静态旗是 **热板块**（昨收二级行业资金均值前 5）：训 +13bp、测 +22bp、全样本 +13bp。已经在 09:35 影子里。

生产池 12 天上，把这些新旗做成 +0.10 加分去换 Top2，**全部不优于分数 Top2**（重叠 1.8–2.0）。不要再拿它们替换模型分。

## 制度切换（走步，不是事后切一段）

377 日，其中延续 134 / 反转 243。

| 规则 | 全样本 T+1 | 胜率 | 训 T+1 / 胜率 | 测 T+1 / 胜率 |
|------|------------|------|---------------|---------------|
| 全市场对照 | +0.26% | 48.9% | +0.33% / 49.7% | +0.03% / 46.4% |
| 永远追 5 日净额前 10% | +0.38% | 48.1% | +0.36% / 47.4% | **+0.45% / 50.0%** |
| 永远做吸筹 | +0.27% | 49.7% | +0.40% / 51.3% | −0.11% / 45.0% |
| **制度切换** | **+0.46%** | **51.9%** | **+0.49% / 52.5%** | +0.32% / 48.5% |
| 热板块（静态） | +0.37% | 48.4% | +0.43% / 48.6% | +0.24% / 48.0% |
| **热板块 ∩ 制度切换** | **+0.54%** | **51.1%** | **+0.56% / 51.5%** | **+0.52% / 50.5%** |

要点：
- 制度切换比「永远追资金」全样本多约 8bp，胜率高约 4 个百分点，左尾也更瘦（5% 深亏 7.7% vs 13.2%）。
- 测试段「永远追」利润略高，因为 2026-04 起资金 IC 连续为正，20 日窗口会晚几周才跟上。这是走步的代价，不是作弊。
- **热板块 ∩ 制度** 在训 / 测两端都稳在 +0.5% 附近、胜率过半。样本更稀（全样本 9438 行），适合当 09:35 软加分，不适合当硬门。

月度 `RankIC(5日净额)`：2025 年多数为负，**2026-04 起转正并维持**（4 月 +0.047 … 8 月 +0.041）。当前影子里的「连续流入 + 小涨」吃的就是这段动量市；制度一旦翻回去，原加分会变拖累。

## 不做什么

- 不把质量 / 加速 / 吸筹 / 强度写进 VM2.5
- 不替换分数 Top2
- 不把「三因子齐」当硬组合
- 分层资金（超大单 vs 散户）、09:35 分钟延续：本地没有足够历史，这次没验

## 建议落地（仍只记影子）

1. 保持现有热板块 / 5 日小涨 / 连续 2 日流入影子。
2. 影子里多记一列：`fund_regime` = 近 20 日已完成 RankIC(sum5) 的符号。
3. 再记一列制度条件旗：热板块且（延续则 5 日净额高、否则吸筹）。
4. 攒满约 20 个交易日，对照制度日 vs 非制度日的影子 Top2，再决定加分是否跟制度走。
