## 2. 因子定义（供 V12 scoring 集成）

### F1【加分项】缩量上涨·低位分 `shrink_up_low_score`

基础字段（信号日 T，全部用 T 及之前数据，无未来函数）：

```
vratio[T] = vol[T] / mean(vol[T-20 .. T-1])          # 前20日均量(不含当日)
pos[T]    = (close[T] - min(low, 60d)) / (max(high, 60d) - min(low, 60d))
ret[T]    = close[T] / close[T-1] - 1
```

触发条件：`1% < ret[T] <= 9.5%` 且 `vol[T] > 0`（剔停牌），然后按连续强度打分：

```
shrink_up_low_score = w1 * (1 - min(vratio, 1.0))      # 量缩越狠分越高
                    + w2 * (1 - min(pos, 1.0))         # 位置越低分越高
```

- **启用条件（六期结论，必须实现）**：仅当「上证指数收盘 ≤ 其 20 日均线」时 F1 参与评分；强市（指数>MA20）F1 权重置 0
- 参考权重 `w1=0.6, w2=0.4`（量比位置更重要，敏感性表支持）
- 二档参考（若需二元化）：**vratio≤0.5 且 pos≤0.3** → 前半胜率 63.2% / 后半 56.1%，样本充足（699/841）
- 敏感性依据：网格 vratio∈{0.4~0.7}×pos∈{0.3~0.5} 全部组合两段跑赢基准，胜率随 vratio↓、pos↓ 单调上升 → 连续打分比硬阈值更合理

### V1【否决/强扣分】放量追涨 `vol_chase_penalty`

触发：`ret[T] > 2% 且 vratio[T] >= 1.5` 且 pos 不在低位（pos>0.4 时扣分更重）。
依据 C2：放量上涨后 5/10/20 日中位数收益全为负。**对普通个股不应因"放量上涨"加分**；仅当个股已识别为题材龙头/主升段（现有龙头识别逻辑）时豁免。

### V2【强扣分】高位横盘+放量突破 `top_breakout_trap`

触发：`pos[T] >= 0.7` 且近 5 日缩量横盘（|ret|≤1%、vratio≤0.5、5日收盘振幅≤4%）后 10 日内出现 `vratio≥1.5 且 ret>2%`。
依据 C3/C5：高位横盘放量突破是全场最差事件（20 日中位数 -1.23%），诱多概率最高。

### F2【观察项，暂不加分】破位超跌反弹 `breakdown_rebound`

触发：低位缩量横盘后 10 日内收盘跌破横盘期 5 日最低价，且当前距破位 0-3 日内。
依据 C4 胜率占优，但**必须**叠加质地过滤（非 ST、非退市整理、无暴雷公告、流动性达标），且与现有"过滤跌停/大涨/涨停/新股"规则合并执行。建议先 Watch 模式跑 5 个交易日统计实际表现，再决定是否转正式加分（沿用 surge ambush 的 Watch 先行流程）。

## 3. 集成点

1. **pipeline_v3 / V12 scoring**：F1/V1/V2 以增量方式并入评分项，权重进配置（环境变量或 config），F1 以 0 权重影子模式上线（计算+落日志、不进评分），弱市开关一并实现；影子跑满 5 个交易日后按实际数据定权重。

## 附录 B：五期跨牛熊检验（2021~2026，主板 769 只 × 约1300交易日）——对置信度的再修正

按自然年切分 20 日表现（胜率%）：

| 年份 | 基准胜率/均值 | F1标准 (0.6/0.4) | F1严 (0.5/0.3) | V1放量上涨 |
|---|---|---|---|---|
| 2021（结构牛） | 53.2% / +2.17% | 50.3% / +1.49% **(跑输)** | 49.7% / +1.61% (跑输) | 51.0% / +2.39% (略赢) |
| 2022（熊市） | 46.2% / +0.08% | **53.5% / +1.37% (大赢)** | 52.1% / +1.10% | 41.9% / -1.07% (大输) |
| 2023（阴跌） | 42.9% / -0.34% | 42.9% / +0.12% (持平) | 45.4% / +1.27% (赢) | 41.3% / -0.70% (输) |
| 2024（震荡） | 46.5% / +0.76% | 43.1% / -0.14% **(跑输)** | 41.5% / -0.39% (跑输) | 49.5% / +2.47% (赢) |
| 2025（牛） | 57.4% / +2.87% | **69.1% / +5.06% (大赢)** | 71.5% / +5.91% | 50.9% / +2.47% (略输) |
| 2026 YTD | 42.3% / -1.09% | **49.6% / +0.82% (大赢)** | 53.4% / +1.29% | 39.5% / -1.81% (大输) |

**对前述结论的三点修正（重要）：**

1. **F1 下调为「多数年份占优、非全天候」**：6 个年度中 4 年跑赢（2022/2025/2026 大赢、2023 严版小赢），2021/2024 跑输，6 年合并胜率约 52.2%（同期基准约 48~49%）。二期"跨期稳健"的说法基于 2024-06 后的窗口，恰好落在有利区间，样本外年份有失效记录。**F1 影子模式 0 权重上线是必须的，不是可选项**；且实盘应叠加市况过滤（弱转强初期/活跃市启用，缩量到极致的冰点期该因子亦失效——2023 就是例子）。
2. **V1 放量上涨的"负期望"分市况**：熊市/弱市（2022/2023/2026）是毒药（胜率 -4pp 以上、均值为负），牛市（2021/2024/2025）接近中性偏弱。否决项保留，且在弱市应加倍扣分——建议 V1 扣分幅度与大盘趋势指标（如指数 20 日线上下）联动。**（注：该联动建议已被附录 C 六期数据撤回——V1 强弱市负超额等幅，无交互，改固定扣分。）**
3. **2025 年 F1 胜率 69~71% 有行情放大成分**（基准本身就 57.4%），影子期预期应锚定"超额 +5~7pp"而非绝对胜率。

数据注意：2019/2020 年基准行受新股连板极端样本污染（不复权+上市初期），已剔除出结论；信号行各年份 n≥20 才计入。

## 附录 C：六期市况联动检验（上证指数 20 日线上/下方，2021-05~2026-09）——最终启用规则

分市况 20 日表现，括号为相对**同市况基准**的超额（基准：强市 46.8%/+0.39%，弱市 49.2%/+1.10%，n≈90 万）：

| 形态 | 强市（指数>MA20） | 弱市（指数≤MA20） |
|---|---|---|
| F1 标准 (0.6/0.4) | 胜率 47.3% **(+0.5)**，均值 +0.31% (-0.08) → **无超额** | 胜率 54.5% **(+5.3)**，均值 +2.13% (+1.02)，中位数 +1.20% → **全部超额来源** |
| F1 严 (0.5/0.3) | 胜率 45.4% (-1.4) → 无超额 | 胜率 55.2% **(+6.0)**，均值 +2.23% (+1.13)，中位数 +1.34% |
| V1 放量上涨 | 胜率 44.9% (-1.9)，中位数 -1.24% | 胜率 47.1% (-2.1)，中位数 -0.74% |

**三点最终修正：**

1. **F1 的启用规则定为：仅弱市（上证收盘 ≤ MA20）加分，强市权重归零。**F1 的全部超额来自弱市——逻辑自洽：弱市里"低位缩量上涨"=抛压枯竭的均值回归起点；强市里低位缩量股只是被资金抛弃的滞涨股（资金聚焦主线，强者恒强）。五期中 2021/2024 两个失败年与强市暴露高度相关。**五期"叠加市况过滤"的建议落地为这条具体规则。**
2. **撤回五期"V1 弱市加倍扣分"的建议**——数据不支持：V1 在强市 -1.9pp、弱市 -2.1pp，两个市况负超额幅度相同，无交互效应。V1 按固定扣分实现即可，无需读指数。
3. F1 弱市中位数为正（+1.20%）→ 是胜率型信号；配合 C4 破位反弹（同为弱市/超跌逻辑），弱市因子组天然成体系。当前（2026-09-04，指数弱市）**正是 F1 的有效窗口**。
