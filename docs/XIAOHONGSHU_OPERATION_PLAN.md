## 四、内容生产 SOP

### 单篇内容生产流程

```
Step 1: 选题（结合日历 + 热点，提前 3 天）
Step 2: 标题（准备 3-5 个备选，用 ChatGPT 做标题 A/B 评分）
Step 3: 正文（800-1200 字，结构：痛点→知识→方案→引导关注/终端）
Step 4: 配图（2-4 张：首图是关键，系统截图/数据图表/代码截图）
Step 5: 标签（15-20 个，覆盖流量标签 + 精准标签）
Step 6: 发布时间（按日历规划）
Step 7: 评论区互动（发布后 1 小时内回复）
```

### 标题公式（小红书特化）

| 公式 | 示例 |
|------|------|
| **Why 型** | 「为什么 90% 的量化的策略实盘就崩？」 |
| **How 型** | 「机构是怎么决定每只票买多少仓位的？」 |
| **比较型** | 「传统量化 VS 在线自进化：差距在哪？」 |
| **数字型** | 「量化系统的一天：从 05:00 到收盘的 7 个关键环节」 |
| **反常识型** | 「量化最大的坑：等权分配仓位」 |
| **实用型** | 「分享一个在线增量学习的 LR 实现（纯 NumPy）」 |

### 首图制作指南

- **风格**：深色背景 + 紫色/蓝色科技感
- **元素**：系统截图、K线图、数据表格、代码片段
- **文案**：大字标题（少于 12 字）+ 小字副标题
- **工具**：Canva / Figma
- **统一视觉**：延续 AlphaPilot 品牌色（紫色 #7C3AED、蓝色 #1E88E5、深色背景）

### 半自动化工作流

```
每天 09:00: AI 生成今日选题 + 标题（根据当前市场热点）
每天 10:00: 人工确定选题，AI 生成初稿
每天 11:00: 人工修改 + 配图
每天 12:00: 定时发布
每天 13:00: 人工回复评论
每周一: 分析上周数据，调整方向
```

> **注意**：小红书对 AI 生成内容有降权风险，务必人工修改 >50% 内容，加入个人经验和观点。

## 八、合规注意事项

### 小红书平台规则红线
- ❌ **不承诺收益**：严禁「稳赚」「保证盈利」「月入 XX」
- ❌ **不诱导开户**：不推荐券商、不引导实盘开户
- ❌ **不晒虚假收益**：如晒收益必须标明「模拟盘/历史回测」
- ❌ **不搞跟单**：不提供「跟着买」「抄作业」
- ✅ **可以展示**：系统架构、策略逻辑、代码片段、回测曲线
- ✅ **可以科普**：量化知识、机构做法、工程经验
- ✅ **可以对比**：不同策略的学术对比、A/B 测试结果

### 话术规范

| 场景 | 推荐话术 | 避免话术 |
|------|---------|---------|
| 介绍系统 | 「搭建了一个在线自进化的量化系统」 | 「这个系统能帮你赚大钱」 |
| 展示回测 | 「历史回测年化 XX%，最大回撤 XX%」 | 「实盘就是这个收益」 |
| 引导访问 | 「可以自己试试看」 | 「快来这里开户跟单」 |
| 对比同行 | 「传统系统通常做的是 XX」 | 「那些做 XX 的都是垃圾」 |

## 九、内容样例

### 样例 1：科普系列「为什么大多数量化策略实盘就崩？」

**标题**：为什么 90% 的量化策略实盘就崩？一个量化工程师的实话

**正文**（要点）：
- 你见过太多回测曲线完美的策略，一上实盘就变样（痛点）
- 原因有三：过拟合历史数据、静态参数不响应市场变化、风控形同虚设（问题）
- 机构怎么做的？在线学习 + 动态仓位 + 分层风控（方案）
- 我自建的系统把这三件事做到了每日自动运行（差异化）
- 想了解更多→关注我，看量化系统的一天

**标签**：#量化交易 #量化策略 #A股 #程序化交易 #Python量化 #量化投资 #交易系统 #AI炒股 #技术分析

---

### 样例 2：工程笔记「在线增量学习的 LR 实现」

**标题**：分享一个在线增量学习的逻辑回归实现（纯 NumPy，30 行）

**正文**（要点）：
- 传统 LR：一次性训练，有新数据要全量重训
- 在线 LR：每来一条数据 partial_fit，权重持续更新
- 核心：学习率衰减 + L2 正则化
- 代码片段展示
- 这个模型我用在量化系统的仓位分配模块
- 完整代码在项目里，关注后私信「代码」获取

**标签**：#Python #机器学习 #逻辑回归 #增量学习 #量化交易 #代码 #编程 #AI
