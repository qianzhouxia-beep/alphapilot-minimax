# AlphaPilot 命名口径（冻结）

更新日期：2026-07-26  
原则：**对人说产品名；对机器用技术 ID。禁止再发明第三套叫法。**

---

## 对外 / 文档 / 对话（唯一口径）

| 层级 | 正式名称 | 含义 | 入口 |
|------|----------|------|------|
| **模型** | **VM2.5** | 生产/验收用的 XGBoost 三模型集成打分器 | `vm25_scorer.py` |
| **管线** | **V3** | 全 A → 金叉 → 打分 → 资金/环境/板块门 → TopN 的漏斗 | `alphapilot_pipeline_v3.py` |

配套说法：

- 「VM2.5 + V3 管线」= 完整日频选股系统  
- 「开盘终选」= 09:35 资金动量三轨（在 V3 日频池之上的盘中重排），**不是**另一个模型版本名  
- ICIR / 隔夜池 = V3 先验输入，**不是**独立模型名  

废弃对外叫法（勿再写进文案）：V25、v25、VM25、V2.5（无 VM）、XGBoost v25、V12 管线（旧）。

---

## 对内技术 ID（允许，但不要当产品名）

这些是文件名 / `model_version` 字段 / 类名，**永远映射到 VM2.5**：

| 技术 ID | 用途 |
|---------|------|
| `v25` | JSON/`model_version` 键、训练元数据 `version` |
| `vm25` | 模块/类前缀：`vm25_scorer`、`VM25Scorer` |
| `v25_opt` / `V25_opt` | 生产选用的 opt 集成权重文件前缀 |
| `v25_base` / `V25_base` | A/B 对照训练臂（非默认生产） |
| `models/v25_opt_ensemble_{1,2,3}.ubj` | 权重文件（勿改名，除非连带迁移脚本） |
| `pipeline_version=v3.1_funnel_gated` | V3 漏斗产物版本串 |

别名兼容（加载时）：`("v25", "vm25", "vm2.5")` → 同一套 VM2.5。

---

## 管线版本串

| 字段 | 正式含义 |
|------|----------|
| `pipeline_version` | V3 漏斗实现标签，当前生产：`v3.1_funnel_gated` |
| `model_version` | 打分器技术 ID，当前生产：`v25`（对外仍说 **VM2.5**） |

---

## 以后怎么写

1. 对用户 / 前端 / 纪要 / 小红书：**VM2.5**、**V3 管线**  
2. 对日志 / API JSON / 文件路径：可保留 `v25` / `v3.1_...`  
3. 新代码注释第一行写产品名，例如：`# VM2.5 scorer (tech id: v25)`  
4. **禁止**再引入 `V26` / `VM3` / `pipeline_v4` 等名字，除非 ADR 正式立项换代
