## 执行方案（分层映射拼接）

```
步骤1: 拉新浪 250 天全量 → data/fund_flow_sina_250.json（纯数据，不动生产文件）
步骤2: 对每只股票，用重叠区(134天) 拟合 y_cur = a * y_sina + b（稳健回归/中位数比）
步骤3: 生产文件拼接 = 新浪早期段 × a + b（仅 134 天之前的日期）+ 现有 134 天原样保留
步骤4: 全市场回归系数分布审计（a 是否集中、残差是否可控）
步骤5: 重训 106 维模型 + walk-forward 对照，确认 AUC 无回退后切生产
```

## 风险控制

- 步骤 1-2 是**只读**操作，不触碰生产 `fund_flow_history.json`。
- 步骤 3 产物先存 `fund_flow_history.v2.json`，等步骤 5 评估通过再原子替换。
- 若某只股票新浪源缺失/异常，回退保留原 134 天（不产生零值）。
