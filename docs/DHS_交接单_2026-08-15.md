## 三、chip 前视贡献实测（方案 B ablate，服务器实跑）

### 方法
复用服务器已构建好的 `output/wb_106d_features_full_20260807.parquet`（1,903,894 行 × 106 特征，含 label，覆盖 2025-01-02~2026-08-07，4960 只）→ 无需重跑特征管线。把 chip 列置 0 重训 XGBoost，对比全特征 AUC。

### 第一版结果（6 个衍生 chip 因子置 0）→ `output/wb_106d_chip_ablate_20260815.json`

| 窗口 | 全特征 AUC | chip-ablate AUC | chip 贡献 |
|---|---|---|---|
| W1（2026-03） | 0.7004 | 0.6997 | **+0.0007** |
| W2（2026-06~07） | 0.6380 | 0.6358 | **+0.0022** |
| 平均 | 0.6692 | 0.6678 | **+0.0015** |

**核心结论**：chip 前视对 0.631 的贡献 ≤ **+0.0022（W2）/ +0.0015（平均）**，几乎可忽略。0.631 的可信度**不依赖 chip 前视**。

**注意**：本实验 W2 全特征 AUC = 0.6380，官方基线 `wb_106d_walkforward_20260807.json` W2 = 0.6301，差 0.008。原因待查：parquet 与官方 json 可能非同一次 run（但量级一致，不影响 ablate 结论）。已补跑**严格版**（全部 11 个 chip 列置 0）待出结果。

| 窗口 | 全特征 AUC | chip-ablate AUC | chip 贡献 |

### 5.1 top2_t1t5 数据脚本修复（用户选定执行）

`scripts/accumulate_top2_t1t5.py` 两处逻辑修复：

1. **非交易日归档剔除**：仅处理真实交易日（交易日集合取自 kline_all.parquet），`2026-07-26`（周日）被正确剔除，rows 12 → 11。
2. **缺失值回填修正**：`close_on()` 目标日无该股数据时返回 `None`（不再回退前一日收盘、不再记 0.0）。

**⚠️ 额外发现并修复的隐藏 bug（DHS 未指出，但比 DHS 问题更严重）**：
- 修复版脚本**缩进结构损坏**：`close_on` 被错误地定义在 `main()` 外（模块级），导致 `main()` 提前返回、后续逻辑全部不执行——这是原脚本在服务器上"跑不完"（日志停在 K 线加载后）的直接原因。
- `np.searchsorted` **缺少 `side="right"`**：导致目标日存在时取到的是**前一个交易日**，T0 基准价全部错一位（如 600206 旧版 t0_close=44.0，正确应为 47.05）。这同时使所有收益率计算基于错误基准。

**验证结果（本地与服务器完全一致）**：

| 项 | 修复前 | 修复后 |
|---|---|---|
| rows | 12（含 07-26 周日） | 11（全为真实交易日） |
| T+1 n | 21 | 19 |
| T+1 正收益 | 15/21（71.4%） | 16/19（84.2%） |
| None 缺失 | 0（误填 0.0） | 0（无缺失、无错填） |
| 600206 07-27 t0_close | 44.0（错，前一日） | 47.05（正确） |

**T+1 从 15/21 变 16/19 的数学自洽性（供复核，含全样本符号翻转表）**：

searchsorted `side="right"` 修复重置了**全部样本**的 T0 基准（非仅 600206），符号翻转共 3 个：

| 样本 | 旧基准/T+1 | 新基准/T+1 | 旧号 | 新号 |
|---|---|---|---|---|
| 600206 有研新材 | 44.0 → +6.93% | 47.05 → -7.55% | + | - |
| 600536 中国软件 | 32.93 → -0.30% | 32.83 → +0.91% | - | + |
| 603983 丸美生物 | 28.67 → -2.48% | 27.96 → +1.22% | - | + |

净变化 = 600206(-1) + 600536(+1) + 603983(+1) = **+1**，15 → 16。剔除 07-26 两样本（旧值 0.0，不计正收益）使 n 21 → 19。故 **16/19 成立**。可运行 `verify_top2_t1_math.py` 复现。
