# Production

日频选股到模拟/实盘执行的线上上下文：漏斗、闸门、打分与交易任务链在此闭环。

## Language

**Production Model**:
当前线上生效的打分模型制品（权重、特征列契约、元数据），由生产任务链加载。
_Avoid_: 实验模型, RD 模型, 候选模型

**Task Chain**:
按日程触发的生产作业序列（如管线、晨间资金重排、信号、执行、巡检），禁止被研发车间直接调用或改写。
_Avoid_: 流水线（单独指选股漏斗步骤时可另用）, 工作流

**Data Support Export**:
生产向研发提供的只读快照或旁路数据，不含下单权与模型写权。
_Avoid_: 共享可写库, 实时双向同步

**Promotion**:
人工批准后，将通过验收的候选模型安装为新的 Production Model 的动作。
_Avoid_: 自动上线, 热更新, 静默替换
