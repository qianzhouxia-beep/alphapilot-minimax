# AlphaPilot 情报层方案（OSINT 隔夜情报 + 异动归因）

> 背景：2026-08-18 用户提出借鉴 Crucix（开源 OSINT 聚合终端），为 AlphaPilot 增加"情报"能力——提供经济指标、突发事件、全球行情等，用于**提前预判/解释 A 股板块异动、指数异动、个股异动**，从而提前预防或准备。
>
> **状态（2026-08-18 晚 更新）：阶段 0 + 阶段 1 + 阶段 3 已落地并部署上线，今天 5:00 管线生效。** 本文为"方案 + 落地状态"合并版。

## 一、需求定位（做什么 / 不做什么）

### 做什么

| 能力 | 说明 | 服务对象 |
|---|---|---|
| **隔夜情报简报** | T-1 晚 / T0 早盘前：美股三大指数、A50 期货、恒指、贵金属/铜/原油、美债收益率、隔夜重大新闻 → 映射"今天哪些板块可能被影响" + 市场环境倾向 | `market_env_gate`、expo 判断、人读简报 |
| **盘中异动归因** | 盘中定时巡检：把盘前情报事件与盘中板块资金告警关联 → 判断"事件驱动脉冲 vs 资金驱动轮动" | 风险规避、避免追高一日游、辅助 research_sector_gate |
| **事后复盘** | 收盘后：今天板块异动与事件的对应关系入库，持续积累映射 | 校验情报准确率、优化映射表（**未实现，见待办**） |

### 不做什么

- **不生成"交易想法"**（不可回测，违背"验证后才上线"）。
- **不做宏观择时 alpha**（情报是慢变量上下文，alpha 仍来自微结构）。
- **不用来追涨事件股**（早盘追强势已被否决；事件股高开低走是常态）。
- **不预测黑天鹅**（只能提前几分钟到几十分钟感知"正在发生的异常"）。

## 三、系统架构（已实现，非设计稿）

```
┌─────────────────────────────────────────────────────────────┐
│                    情报层（项目根目录）                        │
│                                                             │
│  intel_map.py        ← 板块↔事件映射表 + 风险评估（已实现）    │
│  intel_sweep.py      ← 主扫描（逐源容错，已实现）             │
│  intel_brief.py      ← 盘前简报生成 + 微信推送（已实现）       │
│  intel_anomaly.py    ← 盘中异动归因（已实现）                 │
│  （apis/sources/ 目录暂未独立，源模块直接内联在 sweep 中）     │
└──────────────┬──────────────────────────────────────────────┘
               │
   ┌───────────┼───────────────┬──────────────────┐
   ▼           ▼               ▼                  ▼
output/     alphapilot_     intraday_sector_    wecom_push
intel_*    pipeline_v3.py   watch.py 联动        （简报推送）
           （0b 步骤采集）    （盘中归因）
```

**关键设计原则（继承自项目已有习惯 + Crucix 可借鉴点）：**

1. **逐源容错**：单个源失败只记日志跳过，不影响整体（仿 `Promise.allSettled`）。`intel_sweep.py` 每源独立 try-except。
2. **优雅降级**：任何源（含美股因子文件）缺失时，简报退化为可用数据快照，仍可推送。
3. **只输出"上下文"，不改生产逻辑**：情报层产物是 `output/intel_prebrief.json`，生产代码**只读**它做建议/提示，不硬改选股结果。`risk_assessment.enabled=False` 默认关，板块偏好是 `prefer_hint/avoid_hint` 纯提示。
4. **可回测化**：所有情报数据按时间戳落盘（`output/intel_prebrief.json` 每日覆盖 + `output/intel_raw_snapshot.json`），未来可回放做 as-of 回测。

## 四、接入点设计（已接入，含实现细节）

### 4.1 5 点选股管线（已落地，今天 5:00 生效）

`alphapilot_pipeline_v3.py` 第 0 步（原有美股因子+隔夜情绪）之后，新增 **0b 步骤**：

```python
# 0b. 情报层扩源采集（A50/恒指/金银铜油/国内快讯 → intel_prebrief.json）
#     只产出上下文，不改选股结果（INTEL_SECTOR_BOOST 默认 0）；任何异常不阻断管线
ok_intel = run_step("情报层扩源采集", "python3 intel_sweep.py", 60)
if not ok_intel:
    log("  ⚠️ 情报层采集失败（不阻断选股，盘前简报缺失）")
```

`intel_sweep.py` 采集顺序：新浪 hf（A50/金银铜油）→ 腾讯 qt（恒指/恒生科技）→ 东财快讯 → 合并 `us_enhanced_factors.json`（美股/美债）→ `intel_map.build_prebrief()` 组装 → 写 `output/intel_prebrief.json`。实测全程 ~0.3s。

## 七、风险与边界

| 风险 | 应对 |
|---|---|
| 新闻→股价映射噪音大（同消息不同环境反应相反） | 映射表阈值保守 + 事后复盘回写修正 + 验证命中率达标才接入门控 |
| 事件股高开低走 | 情报只用于 expo/偏好，不直接追买；与"早盘追强势被否决"结论一致 |
| 数据源不稳定/收费 | 全部选免费免 Key 源；单源容错 + 优雅降级（已实测 4 源稳定） |
| 过度依赖宏观（慢变量） | 情报是上下文不是 alpha；权重默认 0，逐步验证 |
| 与研报/资金信号冲突 | 走现有 `signal_conflict_detector` 冲突降权机制 |
| 合规（数据使用） | 仅用公开免费数据；不抓付费/爬虫高风险源 |

## 八、验证方法（怎么证明它有用）

1. **简报命中率**：每日盘后对比"简报预测受影响板块" vs "当日实际板块涨幅榜"，统计命中率（阶段 1 门槛 ≥60%）。**08-18 起开始积累样本。**
2. **expo 建议有效性**：比较"建议 expo"与当日指数实际走势（大跌日是否提前降仓）。
3. **as-of 回测**：把落盘的历史 intel 数据回放，接入门控后跑 `bt_research`，对比有无情报层的收益/回撤（对照 A1 基线）。
4. **人工抽样**：每周挑 2~3 个"异动日"人工核对情报-盘面对应关系。
