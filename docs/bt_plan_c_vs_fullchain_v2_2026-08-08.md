## 一、方案 A：5 分钟线精确回测（07-20 ~ 08-07，150 样本）

> 数据: akshare 拉取 73 只 Top10 股票 5 分钟线（06-10 起，1970 bar/只），比服务器 kline5m（仅 07-23 起）多出 07-20/21/22 三个买入日。

| 指标 | Plan C | Full Chain |
|------|--------|------------|
| 毛收益均值 | **0.89%** | 0.78% |
| 净收益均值（扣费） | **0.74%** | 0.63% |
| 胜率 | 52.0% | **53.3%** |
| 平均持仓 | 1.9 天 | 1.9 天 |
| 收益中位数 | 0.43% | **0.57%** |

### 出场原因对比

| 出场原因 | Plan C | Full Chain |
|----------|--------|------------|
| T+1/T+2 尾盘强平 | 106 次 (71%) | 128 次 (85%) |
| 硬止损 | 24 次 (-5% 固定) | 0 次* |
| 跌停 | 3 次 | 12 次 |
| 移动止盈清仓 | 3 次 | 0 次 |
| 到期 | 10 次 | 10 次 |

\* Full Chain 的自适应硬止损（约 -10% 且仅 14:45 后确认）在本期未触发；其"强平"主要体现为 T2_FORCE/T2_FORCE_AFTER_EXT。

### 方案 A 关键发现

**Plan C 的 HARD_SL5 统计（决定性证据）：**
- Plan C 触发 -5% 止损的 24 个样本：均值 **-5.46%**（几乎锁定亏损）
- 同一批股票交给 Full Chain 处理：均值 **-1.55%**（少亏 3.9%）
- 其中贤丰控股、生益科技 2 个样本合计损失约 17% 利润（Plan C 被误杀）

**结论：-5% 固定盘中硬止损是 Plan C 的主要缺陷。** 它把"假跌破"当"真跌"，过早止损锁定亏损；而 FC 的放宽止损 + 尾盘确认能等来反弹。

## 二、方案 B：日线长回测（2025-01 ~ 2026-08，146 样本）

> 数据: 本地 kline_all.parquet（386 交易日，全市场 4991 只），真实推荐池 73 只股票，每 5 个交易日滚动买入池中收盘 > MA20 的前 2 名。
> 注: 日线粒度无法模拟 -3%×3 分钟确认、开盘保护精确窗口、封单率等日内逻辑，只反映日线级趋势差异。

### 总体结果

| 指标 | Plan C | Full Chain |
|------|--------|------------|
| 毛收益均值 | 0.41% | **0.51%** |
| 净收益均值（扣费） | 0.26% | **0.36%** |
| 胜率 | **53.4%** | 49.3% |
| 平均持仓 | 2.0 天 | **2.7 天** |

### 出场原因对比

| 出场原因 | Plan C | Full Chain |
|----------|--------|------------|
| T+1/T+2 尾盘强平 | 113 次 (77%) | 131 次 (90%) |
| 硬止损 | 13 次 (-5% 固定) | 0 次 |
| 跌停 | 12 次 | 15 次 |
| 开盘保护 | 8 次 | - |

### 方案 B 关键发现

**长期（1.5 年）看，Full Chain 的净收益略高（+0.36% vs +0.26%），但胜率更低（49.3% vs 53.4%）。**

原因解析：
- Full Chain 持有更久（2.7 天 vs 2.0 天），靠 T+2 延期吃到了更多反弹段
- Plan C 的 T+1 强平在日线近似下"次日收盘就卖"，过于仓促；但胜率更高说明它"见好就收"
- 日线近似放大了 T+1/T+2 差异，因为日线没有尾盘时段概念，Plan C 等于"次日收盘即卖"

## 三、两套回测的交叉验证

| 维度 | 方案 A（5 分钟线） | 方案 B（日线） | 一致性 |
|------|-------------------|----------------|--------|
| 净收益对比 | Plan C 0.74% > FC 0.63% | Plan C 0.26% < FC 0.36% | **矛盾** |
| 胜率对比 | Plan C 52.0% < FC 53.3% | Plan C 53.4% > FC 49.3% | **矛盾** |
| Plan C -5% 止损缺陷 | 显著（误杀 2 样本损失 17%） | 轻微（13 次止损） | **一致：-5% 止损拖累收益** |
| FC T+2 延期价值 | Top2 下 FC 略逊 | 长周期 FC 收益略高 | 部分一致 |

### 为什么两套结果"矛盾"？

核心原因：**日线近似改变了 Plan C 的 T+1 强平时点**。
- 真实 Plan C：T+1 强平在 **14:45 尾盘**，用封单率判断，当天还有 1 小时可以反弹
- 日线近似：T+1 强平 = **次日收盘价**（日线无尾盘概念），等于"拿到收盘前最后一刻"
- 所以日线近似**有利于 Plan C**（多给了几乎一天观察时间）却让它更早离场

而 5 分钟线精确回测里：
- Plan C 的 -5% 止损在盘中触发（把反弹前的洗盘当作趋势）
- Full Chain 的放宽止损 + 尾盘确认更耐心

### 真正稳健的结论（两套回测一致支持）

1. **-5% 固定盘中止损弊大于利**（两套回测都显示其拖累收益）
2. **尾盘强平前应给"反弹机会"**（FC 的延期机制在长周期略优）
3. **Plan C 的胜率优势来自"快进快出"**，但付出的代价是止损误杀

## 四、融合方案建议（v3）

基于两套回测交叉验证，推荐融合策略：

```
【买入】保持 GapSoft C 入口（两者相同）

【卖出】融合 Plan C 骨架 + Full Chain 灵活退出：
  1. 开盘保护: 09:35-09:45 -7% 全卖          ← Plan C（保留，已证明有效）
  2. 阶梯止损: -3% 连续 3 分钟半仓            ← Plan C（保留，快速降险）
  3. 硬止损: -5% 固定 → 改为 -7% 且仅 14:45 后确认  ← 融合（消除误杀）
  4. T+1/T+2 尾盘决策: 
     - 第 1 天(14:45): 封单强(≥0.999涨停价) 持有
     - 价格 ≥ 成本×0.95 → 延期 1 天           ← FC（给反弹机会）
     - 否则 → 卖出                          ← Plan C（快速退出）
  5. 移动止盈: arm≥3% + 回撤 1.5% 半仓, 最多 3 刀 ← 两者相同
  6. Book A8/A4 提前退出                      ← Plan C（保留）
```

### 设计理由

| 改动 | 理由 | 依据 |
|------|------|------|
| -5% → -7% 且尾盘确认 | 消除误杀 | A/B 两套回测均显示 -5% 拖累 |
| 引入"≥0.95 延期 1 天" | 给强票反弹机会 | FC 长周期净收益更高 |
| 保留 T+1 快速退出 | 控制胜率优势 | Plan C 胜率两套均 ≥52% |
| 保留封单率决策 | 实盘有真实 bidVol1 | Plan C 独有优势 |

## 五、局限性

1. 方案 A 仅 15 个交易日、150 样本，仍是短期窗口
2. 方案 B 用真实推荐池 73 只股票滚动买入，有**幸存者偏差**（这些股近期被选中，长期历史可能偏强）
3. 方案 B 日线近似丢失 -3%×3 分钟确认、开盘保护精确窗口、封单率等日内逻辑
4. 封单率用收盘封板近似（历史无 bidVol1），实盘 QMT 有真实封单数据
5. 未考虑滑点、停牌、涨跌停无法成交等细节
6. 方案 B 的买入信号（收盘 > MA20 前 2）是对真实选股逻辑的近似
