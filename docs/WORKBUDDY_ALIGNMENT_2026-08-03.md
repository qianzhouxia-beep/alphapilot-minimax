### 2.2 OOS 评估口径（用户拍板，优先级最高）

**模型定位：T+1 短线。** 用户明确：
- 模型目标 = **今天买入，明天（T+1）涨 3%**（`FORWARD_DAYS=1`）
- 止盈触发 = **明日盘中触及 +3%**（不是"收盘站上 +3%"）
- 若 T+1 未达 3% → 继续持有，直到触发 3% 止盈或止损

**因此**：
- 生产模型标签就是 fd=1（服务器 `train_v25.py` 第 37 行 `FORWARD_DAYS=1` 已核实）
- **标准 OOS = 新特征管线 + fd=1 + 标签=盘中触及 +3%**（`high[明日]/close[今日]-1 > 3%`）
- WorkBuddy 的 **fd=5 OOS（0.533）口径错误**，测的是另一个预测目标，不作为基准

## 三、QMT 实盘策略（2026-08-03 更新）

### 3.1 架构

QMT **模型内运行**（非 qmt_bridge 方案，该方案已废弃）：
- 文件 `qmt_model_plan_c.py`（本地，用户粘贴到 QMT 模型编辑器）
- 自动读取真实持仓 → 纯卖出管理（不做买入）
- 与云端 AlphaPilot 选股解耦，只负责已持仓的止盈止损

### 3.2 跟踪止盈（替换原固定档位）

用户澄清真实止盈逻辑 = **跟踪止盈**：
1. 触发：明日盘中触及 **+3%** → 激活跟踪（不卖）
2. 后续：继续涨 → 继续持有，峰值跟着涨
3. 卖出：从峰值回撤 **1.5%** → 减半锁利

| 参数 | 值 | 含义 |
|---|---|---|
| `TP_ARM_PCT` | 3.0 | ≥3% 激活跟踪（记录峰值） |
| `PEEL_PULLBACK_PCT` | 1.5 | 峰值回撤 1.5% → 减半 |
| `PEEL_MAX_STEPS` | 2 | 前两次减半，第三次清仓（共 3 刀） |

关键行为（与 `trade_executor.py` 的 `TRAIL_ARM=3% + PEEL_PULLBACK=1.5% + PEEL_MAX_STEPS=2` **完全一致**）：
- 减半后须**再创新高**才允许下一刀（防回撤途中连续割）
- 浮盈消失（<0%）→ 退出跟踪，回到 -3% 分级止损 / -5% 硬止损框架
- 剩余不足 2 手 → 直接清仓（A股最小 100 股）

### 3.3 其他保留的 Plan C 逻辑

- **止损**：-3% 连续 3 分钟减半 / -5% 硬止损 / 开盘保护（09:35-09:45 -7%）/ 跌停 -9.5% 全卖
- **封成比分层决策**（14:45 后）：封成比>3 → 持有过夜；>1+低换手(<5%) → 持有；否则次日走（基于 5835 样本实证校准）
- **T+1 合规**：今日买入不可卖（跌停除外）

## 四、实证研究（2026-08-02 完成）

### 4.1 封成比（封单成交比）实证研究

**数据**：2026-04-01 ~ 07-31，同花顺涨停池 6,374 条涨停 → 有效 5,835 条（含次日行情）。

| 档位 | 样本 | 次日开盘溢价 | 次日收盘溢价 | 连板率 |
|---|---|---|---|---|
| 封成比>10 | 28 | +11.05% | +9.29% | 85.7% |
| 3~10 | 43 | +10.54% | +10.00% | 88.4% |
| 1~3 | 142 | +5.59% | +4.69% | 43.7% |
| <1 | 5,622 | +1.53% | +1.32% | 15.7% |
| <0.5 | 5,277 | +1.45% | +1.31% | 15.4% |

**关键结论**：
- 五档方向正确、单调性显著。
- **必须分板型**：一字板封成比>3 → 次日+10.9%（连板率 88.6%）；换手板封成比>1 → 仅+2.9%。
- **换手率是最大干扰因子**：低换手(<5%)+封成比>1 → 次日+7.4%、连板率 58%（最优）；高换手(>20%)即使封成比高次日也是负溢价。

### 4.2 非涨停强势股验证（69,052 样本）

- 总体：次日开盘 **-0.38%**，开盘胜率仅 34.8%。
- 换手率分层：换手>20% → -1.34%（最差）；换手<3% → +0.01%。
- **结论：封成比体系不能泛化到非涨停股**。非涨停股无封单，封成比概念不成立；当日大涨+高换手次日大概率低开。

### 4.3 非涨停股"共通因子"探索

- **CLV 收盘位置值验证失败**（方向相反）。
- **真正的共通因子 = 换手率（缩量程度）**：换手<1% + 当日涨5%+ 是唯一正溢价档（3%止盈实收 +0.93%），但量级远低于涨停股，**无次日交易价值**。

**结论**：非涨停强势股整体不构成买入策略；封成比的价值仅在 QMT 持仓端（已涨停持仓的隔夜/出货决策）。
