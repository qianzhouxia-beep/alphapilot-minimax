## 二、全书 7 条核心哲学（对模型设计的启发）

1. **位置决定一切**：同一种 K 线形态在不同位置意义相反（高位上吊线=见顶，底部单针探底=见底；高位避雷针=逃命，首波拉升避雷针=还有第二波）。任何指标必须先回答"当前处于庄家循环的哪个位置"。
2. **价格是因，指标是果**："不是指标决定股价，而是股价决定指标"。超卖可以更超卖，超买可以钝化。
3. **量是最难造假的语言（庄家第二死穴）**：建仓放量、出货放量、洗盘缩量；底量顶量对等原则判断真顶底。
4. **避险第一，获利第二**：本金安全凌驾于一切技术。
5. **操作优劣不在于每次获利幅度大小，而在于能否必然获利**：与我们的 T+1 高触 +3% 高确定性止盈定位同构。
6. **大周期压制小周期**：周线均线压力远大于日线，月线远大于周线。日线均线多头却冲不上去→看周线/月线找"无影杀手"。
7. **30 日均线是短线生命线**："80% 以上的被套，问题都出在 30 日均线方向"。

## 三、可提取的因子（三档）

### A 档：量化定义明确、可直接加进 `features_v2.py` / 做成 Gate

| # | 因子 | 书中规则 | 现有体系状态 |
|---|------|---------|------------|
| A1 | **MA30 方向/斜率** | MA30 向下→赢利概率仅两成；向上且股价在其上方→可大胆操作 | **缺失**（现有只有 sma_5/20/60 与交叉，无 MA30 方向态） |
| A2 | **布林上轨占位天数** | 收盘连续站上布林上轨 ≥4 个交易日→85% 概率回调 | **缺失** |
| A3 | **高位单日巨量** | 相对高位放单日天量（≥近月次天量）→无论阴阳都是预警 | **缺失**（现有 vol_ma_ratio 无"位置+异常量"联合判定） |
| A4 | **高位大阴线** | 相对高位单日跌幅 >6%→庄家坚决抛货，不碰 | **缺失** |
| A5 | **CCI 破百卖出** | CCI 从高位干脆跌破 100→必须卖出；缠绕式破百可卖可不卖 | **缺失**（模型无 CCI） |
| A6 | **CCI 超跌买点** | CCI<-200 小注进场，5日/20日均量线金叉→重手加仓 | **缺失** |
| A7 | **月/周 KDJ 大级别信号** | 月 KDJ J<20 且周 J<10→暴涨孕育；月 J>80 且周 J>90→暴跌降临 | **缺失**（可用 120 日近似月线、30 日近似周线） |
| A8 | **高位大量 + RSI≥80** | 中高位放单日大量且 RSI 达 80+→精确卖出信号 | 部分（RSI 已有，无此组合） |
| A9 | **高位双死叉** | 5日/10日均线相隔不久两次死叉→见顶 | 部分（有 ma_cross_5_20，无"二次死叉"状态机） |
| A10 | **55日均线破位首反抽** | 跌破 55 日线后首次回抽→必卖；二次攻回+缩量阴线确认→买点，不破可持有 | **缺失** |

### B 档：高胜率形态因子（需模式识别工程化，适合做事件因子/二次打分）

1. **放量长阴回调狙击法（书中胜率>90%）**，本质是"洗盘识别"：
   - 涨停或 ≥7% 大阳 → 次日**高开≥5%** + **放量长阴** + 不下破前阳中点
   - 后续 2 天内：最低不破长阴低点、最高攻上长阴 1/2、至少一根量≥长阴 1/3、分时大部分时段在 1/2 价位震荡
   - → 第 3 个交易日择机买进
2. **巨量假阴线（5% 超短线绝招）**：量比≥3~4 倍的巨量高开低走假阴线 → 小平台整理（重心在假阴 1/2 上方）或两周内回升至假阴开盘价附近 → **突破假阴开盘价日必须放量**（≥假阴量一半，缩量突破无效）→ 尾盘买进。与 `call_auction_factors.py` 已有 `fake` 因子相关但更完整。
3. **旗形突破**：旗杆=1~3 根真阳快拉（不可掺假阳）；旗面=5~11 根 K 线、向下 60°~80°；突破=中阳以上收盘站稳上轨。强势逼空型（次日 ≥5% 大阳）或稳健回探型（缩量阴线不跌回箱体、回调不破前阳实体 1/3）→ 回探后 5 日上穿 10 日金叉处买入。
4. **30日均线首次破线买点**：趋势恢复向上后**第一次**回踩破 MA30→95% 是庄家烟幕弹、绝佳低买点；第 3~4 次破线才见顶（第 4 次破线临盘必卖）。
5. **均线黏合圆弧底（"旭日东升"）**：30/60/115/225 四线高度黏合 + MACD 低位金叉 + 破位后圆弧底反抽攻上黏合带→预期 +50%。
6. **周线多头炮**：破位周阴后两阳夹一阴、第三根阳线量放大→周五尾盘买。**书中强调日线多头炮庄家造假成本低仅五成可靠，周线多头炮货真价实**——启发：大周期形态信号权重应高于小周期。

### C 档：pipeline 硬性过滤 Gate（对应"七种股票不要碰"）

1. **30 日均线朝下 → 过滤**（赢利概率 20%）
2. **下降通道形态 → 过滤**（书中：7 成亏损源于下降通道盲目操作）
3. **大周期均线压制 → 过滤/降权**（30周/60周/5月线压头顶，日线可近似 MA150/MA250）
4. **大幅除权半年内 → 过滤**（均线/指标系统被破坏，填权概率仅 50%）
5. **高位天量 → 预警降权**
6. **高位单日 >6% 大阴线 → 过滤**
7. **卖出型 K 线当日 → 减仓/清仓**（上吊线、避雷针、墓碑线、断头铡刀、空中飞刀、双子塔、高位阴阳并线）

## 四、落地建议（按 ROI 排序，供讨论）

1. **【最高 ROI】MA30 方向态 + 位置归一化**
   - `features_v2.py` 增加：`ma30_slope`（MA30[t]/MA30[t-3]-1）、`close_vs_ma30`、`ma30_up`（binary）；pipeline 硬 gate 加"MA30 方向向下直接剔除"。
   - 加**位置百分位因子** `price_quantile_250`（股价在 250 日区间的位置），让 XGBoost 学会"同一形态在不同位置"差异化打分——Top50→Top2 重排最缺的维度。
2. **【高 ROI】量能位置特征**（庄家第二死穴）
   - 在 `vol_ma_ratio` 之上增加：`low_vol_consec_days`（地量收敛天数，对应"池底形态"≥20 日）、`high_vol_at_high_pos`（高位放量警示）、`top_vs_bottom_vol_ratio`（底量顶量对等原则）。
3. **【高 ROI】卖出信号因子联动 T+1 止盈**
   - 持仓股当日出现上吊线/避雷针/高位双死叉/CCI 破百/大量+RSI80→不等回撤直接先减仓，作为 QMT 跟踪止盈的增强/提前离场信号。
4. **【中高 ROI】洗盘-突破二段式事件因子**
   - 把 B1（放量长阴）+ B2（巨量假阴）编码为"洗盘信号日"，再编码"确认买点"（突破日放量≥洗盘日一半）。可作为 `call_auction_factors.py` 增强因子，服务 09:35 从 500 选 Top2。
5. **【中 ROI】CCI/KDJ 多周期共振因子**
   - CCI 破百、CCI<-200、月/周 KDJ J 值极值（日线近似：120 日≈月线、30 日≈周线）。对顺势放大仓位/极端避险有补充价值。
6. **【工程注意】避免过度拟合**
   - 书中阈值（高开 5%、1/2、1/3、4 日、6% 等）是作者手工经验值。落地时应做成可调参数并用历史回测验证（T+1 高触 +3% 标签做 IC/分组回测），不直接照抄——与封成比策略的数据驱动验证流程一致。
