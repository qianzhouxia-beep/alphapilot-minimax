## 1. 研究背景与目标

用户提出量价组合的经典口诀问题：缩量横盘、放量上涨、缩量上涨各代表什么？未来走势如何？

处理原则：**口诀是经验之谈，样本偏差严重，先用大样本数据验证，再决定是否进模型。** 六轮回测依次回答：

1. 一期：六大量价形态在主板的真实胜率/收益分布（对照随机买入基准）
2. 二期：结论跨期是否稳健（牛熊两半段）+ 经典"缩量横盘等放量突破"打法有无增益
3. 三期：F1 参数是否过拟合（24 组网格单调性）
4. 四期：20cm 板块（创业板/科创板）是否成立
5. 五期：拉长到 2021~2026 跨完整牛熊，按年度检验
6. 六期：定位超额来源（大盘强/弱市），产出最终启用规则

## 2. 数据与方法论

### 2.1 形态量化定义（信号日 T，全部只用 T 及之前数据，无未来函数）

基础字段：

```
ret[T]    = close[T] / close[T-1] - 1
vratio[T] = vol[T] / mean(vol[T-20 .. T-1])        # 注意：前20日均量不含当日（实现用 shift(1)/REF(...,1)）
pos[T]    = (close[T] - min(low,60d)) / (max(high,60d) - min(low,60d))   # 0=60日最低, 1=最高
amp5[T]   = max(close,5d) / min(close,5d) - 1      # 近5日收盘振幅
```

六形态触发条件（信号行之间同一形态 5 日去重，避免自相关）：

| 形态 | 条件 |
|---|---|
| 放量上涨 | ret > 2% 且 vratio ≥ 1.5 |
| 放量下跌 | ret < -2% 且 vratio ≥ 1.5 |
| 缩量上涨·低位 | 1% < ret ≤ 9.5%（20cm 板 ≤19.5%）且 vratio ≤ 0.6 且 pos ≤ 0.4 |
| 缩量上涨·高位 | 同上但 pos ≥ 0.7 |
| 缩量横盘·低位 | \|ret\| ≤ 1% 且 vratio ≤ 0.5 且 amp5 ≤ 4% 且 pos ≤ 0.4 |
| 缩量横盘·高位 | 同上但 pos ≥ 0.7 |
| 放量突破（二期用） | vratio ≥ 1.5 且 ret > 2% |
| 有效跌破（二期用） | close < min(low, 横盘期5日) |

统一口径：剔停牌（vol=0）；股票池剔除 ST/*ST/退市；前瞻收益 fwdN = close[T+N]/close[T]-1（N=5/10/20），要求 T+N 数据存在。

### 2.2 基准定义（关键：任何形态的价值 = 跑赢基准多少）

基准 = 同一股票池全部有效交易日随机买入并持有 N 日的平均表现。**不看绝对胜率，只看相对基准的超额。**

### 2.3 无未来函数声明

所有字段仅用 T 及之前数据；vma20 用 `shift(1)`（等价通达信 `REF(MA(VOL,20),1)`）；单元测试必须验证 shift 方向（见第 7 节清单）。

## 4. 最终因子规范（Cursor 实现依据）

### 4.0 市况开关（全局，F1 专用）

```
REGIME_WAK = (INDEX_CLOSE <= MA(INDEX_CLOSE, 20))    # 上证指数收盘 ≤ 其20日均线 → 弱市 → F1 启用
```
- 指数数据从现有管线取，勿新增依赖；当日指数收盘在盘中用最新价（与回测口径的偏差可接受，影子期验证）
- 强市时 F1 权重置 0（仍计算、仍落影子日志）

### 4.1 F1【加分项，影子模式】缩量上涨·低位分 `shrink_up_low_score`

```
触发前提: 1% < ret ≤ R_CAP 且 vol > 0 且 REGIME_WAK
        （R_CAP: 10cm 板=9.5%, 20cm 板=19.5%；一字板因 ret 上限自然排除）
连续分:  score = w1 * (1 - min(vratio,1.0)) + w2 * (1 - min(pos,1.0))
        参考 w1=0.6, w2=0.4（量比位置更重要）
二元备选: vratio≤0.5 且 pos≤0.3（回测 20日: 弱市胜率 56.1%~55.2%+，样本充足）
```

### 4.2 V1【扣分项】放量追涨 `vol_chase_penalty`

```
触发: ret > 2% 且 vratio ≥ 1.5
扣分: 固定幅度（不与市况联动——六期证明无交互）; pos>0.4 时可加倍
豁免: 个股已被现有龙头识别逻辑标记为题材龙头/主升段
```

### 4.3 V2【强扣分】高位横盘+放量突破 `top_breakout_trap`

```
触发: pos ≥ 0.7 且近5日满足横盘定义(|ret|≤1%, vratio≤0.5, amp5≤4%)
      且其后10日内出现 vratio≥1.5 且 ret>2%
依据: 20日中位数 -1.23%，全场最差事件（诱多出货末端）
```

### 4.4 F2【观察项，Watch 模式】破位超跌反弹 `breakdown_rebound`

```
触发: 低位(pos≤0.4)缩量横盘后 10 日内收盘 < 横盘期5日最低价, 且距破位 0~3 日
必须: 质地过滤（非ST/非退市整理/无暴雷公告/流动性达标）+ 与现有跌停/大涨/涨停/新股过滤合并
流程: Watch 5 个交易日 → WorkBuddy 复核 → 拍板是否转正式加分
```

### 4.5 参考实现（Python 骨架，可直接对照写测试）

```python
def compute_vp_factors(df, index_close, index_ma20):
    """df: 单股日线 DataFrame(日期升序): open/high/low/close/vol/amount
       index_close/index_ma20: 与 df 日期对齐的上证指数收盘与20日线(Series)"""
    close, vol = df['close'].astype(float), df['vol'].astype(float)
    low = df['low'].astype(float)
    ret = close.pct_change()
    vratio = vol / vol.rolling(20).mean().shift(1)          # 关键: shift(1) 不含当日
    pos = (close - low.rolling(60).min()) / (df['high'].astype(float).rolling(60).max() - low.rolling(60).min())
    amp5 = close.rolling(5).max() / close.rolling(5).min() - 1
    valid = (vol > 0) & vratio.notna() & pos.notna() & ret.notna()

    weak = (index_close <= index_ma20).reindex(df.index).fillna(False)
    r_cap = 0.095  # 20cm 板传 0.195

    f1_sig = (ret > 0.01) & (ret <= r_cap) & (vratio <= 0.6) & (pos <= 0.4) & valid & weak
    v1_sig = (ret > 0.02) & (vratio >= 1.5) & valid
    flat5  = (ret.abs() <= 0.01) & (vratio <= 0.5) & (amp5 <= 0.04) & valid
    v2_sig = (pos >= 0.7) & flat5 & (vratio >= 1.5) & (ret > 0.02) & valid
    # F2: flat5低位信号后10日内 close < 前5日最低, 距破位0~3日 (状态机实现, 此处略)

    f1_score = 0.6 * (1 - vratio.clip(upper=1.0)) + 0.4 * (1 - pos.clip(upper=1.0))
    return {'f1_signal': f1_sig, 'f1_score': f1_score.where(f1_sig, 0.0),
            'v1_hit': v1_sig, 'v2_hit': v2_sig, 'weak_regime': weak}
```

## 附录 B：独立通达信公式（仅限人工看盘，严禁并入 AlphaPilot 代码库）

```
{F1缩量上涨低位·选股 | 独立公式,与AlphaPilot系统严禁混用 | 数据源:通达信}
VOLMA20:=MA(VOL,20);
VRATIO:=VOL/REF(VOLMA20,1);          {关键: REF 取前20日均量,不含当日}
LOW60:=LLV(LOW,60);
POS:=(CLOSE-LOW60)/(HHV(HIGH,60)-LOW60);
RET:=CLOSE/REF(CLOSE,1)-1;
WEAK:=INDEXC<=MA(INDEXC,20);          {弱市: 对应指数(沪市=上证)收盘<=20日线}
F1COND: RET>0.01 AND RET<=0.095 AND VRATIO<=0.6 AND POS<=0.4 AND VOL>0 AND WEAK;
{V1放量追涨·预警}
V1COND: RET>0.02 AND VOL>=1.5*REF(VOLMA20,1);
```

使用边界：此公式仅用于通达信电脑版人工看盘/选股（与 Level-2 盘口观察配合），其输出不得作为 AlphaPilot 数据源，AlphaPilot 因子代码亦不得引用本公式。

## 附录 C：实现常见问题（FAQ）

- **Q: 为什么排除 ret>9.5%/19.5%？** 排除涨停/一字缩量板——那是独立形态（惜售封板），混入会污染 F1 统计。
- **Q: vratio 为什么必须 shift(1)？** 当日放量/缩量是相对"之前"的度量，把当日算进分母会稀释信号。TDX 对应 `REF(MA(VOL,20),1)`。
- **Q: 为什么只用不复权？** 与回测口径一致；前复权在回测起点附近有边界失真。个股除权日的信号少量噪声，大样本可忽略。
- **Q: V1 为什么不豁免所有强势股？** 仅豁免已有龙头识别标记的个股；无标记的放量上涨平均是负期望（一/四/六期一致）。
- **Q: F1 为什么强市关闭？** 六期：强市超额 +0.5pp≈0 且中位数为负，开着只添噪声。
