## 一、融合方案 V3 定义

```
【卖出】融合 Plan C 骨架 + Full Chain 灵活退出：
  1. 开盘保护: 09:35-09:45 -7% 全卖          ← Plan C
  2. 阶梯止损: -3% 连续 3 分钟半仓            ← Plan C
  3. 硬止损: -7% 且仅 14:45 后确认            ← 融合（Plan C -5% 放宽 + FC 尾盘确认）
  4. T+1/T+2 尾盘决策:
     - 封单强(≥0.999涨停价) → 持有            ← Plan C
     - 否则首次尾盘 → 延期 1 天给反弹机会     ← FC
     - 已延期 → 卖出                         ← FC T+2 强平
  5. 移动止盈: arm≥3% + 回撤 1.5% 半仓, 最多 3 刀 ← 两者相同
  6. Book A8/A4 提前退出                      ← Plan C（回测未模拟）
```

## 四、关键发现

### 1. 融合 V3 未达到预期：没有同时获得两者的优势

融合 V3 的设计初衷是"Plan C 快速止血 + FC 耐心反弹"，但回测显示它**两头不讨好**：

- **方案 A**：融合 V3（0.67%）介于 Plan C（0.74%）和 FC（0.63%）之间，未超越 Plan C
- **方案 B**：融合 V3（0.09%）**明显垫底**，远低于 Plan C（0.26%）和 FC（0.36%）

### 2. 根因：T+2 延期在"真跌"样本上两头受损

融合 V3 的 T+2 延期机制让它持有更久。这带来两个后果：

- ✅ **假跌破**（如 07-24 生益科技）：Plan C -5.7% 误杀，融合 V3 +1.1% 等到反弹（**+6.8% 优势**）
- ❌ **真跌**（如 07-27 臻宝科技、07-20 航天环宇）：Plan C -5.2%/-5.7% 止损，融合 V3 -9.8%/-10.0% 吃满跌停（**-4.3%~-4.6% 劣势**）

**融合 V3 在 Top2 子集的最大差距样本就是 07-20 688523（Plan C -5.7% vs 融合 V3 -10.0% LIMIT_DOWN）**，一次跌停吃满亏损抵消了多次反弹收益。

### 3. Plan C 的 -5% 止损是"双刃剑"但净效果在样本期内偏正

- 24 次 -5% 止损中有约一半是"误杀"（后续反弹），约一半是"真跌"（及时止血）
- 但在 Top2 子集（策略实际买入）中，Plan C 收益最高（1.28%），说明**快速止损在 Top2 上更有效**
- 融合 V3 放宽止损到 -7% + 延期，反而让真跌样本吃满亏损

### 4. 硬止损阈值敏感性（方案 A）

| 硬止损阈值 | 净收益 | 胜率 | HARD_SL 次数 |
|------------|--------|------|-------------|
| -5% | 0.67% | 53.3% | 13 |
| -6% | 0.67% | 53.3% | 7 |
| -7% | 0.67% | 53.3% | 7 |
| -8% | 0.68% | 53.3% | 2 |
| -9% | 0.68% | 53.3% | 0 |

**结论：融合 V3 的收益主要由 T+2 延期机制决定，硬止损阈值影响很小（-5% 到 -9% 收益都在 0.67-0.68%）。** 这进一步证明融合 V3 的收益瓶颈在延期机制，而非止损参数。

## 五、结论与建议

### 两套回测综合排名

| 方案 | 第 1 名 | 第 2 名 | 第 3 名 |
|------|--------|--------|--------|
| 方案 A（5 分钟线） | Plan C (+0.74%) | 融合 V3 (+0.67%) | FC (+0.63%) |
| 方案 B（日线长周期） | FC (+0.36%) | Plan C (+0.26%) | 融合 V3 (+0.09%) |

### 核心结论

1. **融合 V3 在 5 分钟线回测中排第二，日线长周期回测中垫底**——它不是更优方案，反而牺牲了 Plan C 的快速止血优势，又没完全获得 FC 的耐心优势。

2. **Plan C 和 FC 代表了两种不同的风险偏好**：
   - **Plan C**：快进快出，胜率 52-53%，适合震荡市（样本期 A 占优）
   - **FC**：耐心持有，靠 T+2 延期吃反弹，适合趋势市（样本期 B 占优）

3. **融合的方向不对**：把"快速止损"和"耐心持有"强行融合，在真假跌破无法区分时两头受损。

### 建议的修正方向

与其"融合两种完全相反的退出哲学"，不如**做条件化选择**：

1. **保留 Plan C 作为默认卖出**（Top2 子集收益最高，胜率最高）
2. **增加一个可选的"封单强则持有"开关**（Plan C 已有，但在 T+1 尾盘判断封单）
3. **若要吸收 FC 的延期优势，只针对"盈利且接近涨停"的票延期**，而非所有票：
   - 盈利 ≥ 3%（arm 触发）且封单强 → 延期观察
   - 亏损或封单弱 → 立即按 Plan C 逻辑退出
4. **硬止损保持 -5%（Plan C）或最多放宽到 -6%**，不做 -7% + 延期（会吃满跌停）

### 最终建议

**当前 QMT 模拟端继续用 Plan C（qmt_model_plan_c.py）**，它是三方中最稳健的（Top2 子集最优、方案 A 最优、方案 B 次优）。

若想吸收 FC 的价值，只做一个小改动：**给 Plan C 增加"盈利 ≥ 3% 且封单强 → 延期 1 天"的开关**，其余保持不变。这样既保留 Plan C 的快速止损，又能让强势股多跑一天。

### 改动内容

1. **新增参数 `PROFIT_GATE_PCT = 3.0`**（盈利门槛）

   - 原逻辑: 14:50 T+1 尾盘判断封单，`seal>3` 或 `seal>1+低换手` → **无论盈亏一律延期 1 天**


## 六、局限性

1. 方案 A 仅 15 个交易日、150 样本（含 Top2 30 样本），仍是短期窗口
2. 方案 B 用真实推荐池 73 只股票滚动买入，有幸存者偏差
3. 方案 B 日线近似丢失 -3%×3 分钟确认、开盘保护精确窗口、封单率等日内逻辑
4. 封单率用收盘封板近似（历史无 bidVol1），实盘 QMT 有真实封单数据
5. 融合 V3 的 Book A8/A4 提前退出逻辑未在回测中模拟（依赖 RSI/成交量，历史数据不完整）
6. 未考虑滑点、停牌、涨跌停无法成交等细节
