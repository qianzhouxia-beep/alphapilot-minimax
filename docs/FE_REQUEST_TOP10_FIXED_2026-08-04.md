## 三、后端现状（已改造完成 2026-08-04 中午）

**数据源：`/home/ubuntu/alphapilot/output/score_top10.json`**
- `mode`: `fusion_3way`
- 09:35 终选候选（`daily_recommend.json` 的 `recommendations`）优先，其他源兜底

**每只候选注入字段**：
| 字段 | 说明 |
|------|------|
| `score` | 原始模型分（保留展示） |
| `_fusion_weight` | 综合分 0~1（排名依据） |
| `_fusion_scores` | `{vm25, fund_flow, sector_heat}` 三因子明细 |
| `main_net` | 主力净流入 |
