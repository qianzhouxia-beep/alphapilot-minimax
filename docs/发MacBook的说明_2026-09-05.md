# 发 MacBook 的说明 · AlphaPilot 迁机第一步

> 用途：把「在 Mac 上开始用 AlphaPilot」的最小步骤发给 Mac（微信 / 备忘录 / 邮件 / 隔空投送均可）。
> 更新：2026-09-05。仓库已推 `master`（commit `298ba9b3`）。

---

## ① 拿代码（Mac 终端执行，选一种）

```bash
# 首次：克隆整个仓库
git clone https://github.com/qianzhouxia-beep/alphapilot-minimax.git

# 若 Mac 上已有该仓库：直接拉最新
cd alphapilot-minimax && git pull
```

## ② 先读这两份文件

- 迁机清单：`knowledge/ops/macbook-migration-checklist.md`
- WorkBuddy 交接（若要让 Mac 上的 WorkBuddy 干活）：`docs/WORKBUDDY_HANDOFF.md`

## ③ 网页链接（打不开就用下面 raw 下载）

- 仓库：https://github.com/qianzhouxia-beep/alphapilot-minimax
