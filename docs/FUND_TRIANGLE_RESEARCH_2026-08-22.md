# 资金三角：板块好 / 龙头好 / 待涨好

日期: 2026-08-22  
口径: 特征只用到 D 开盘前（资金 asof = 严格早于 D 的最近一日）；买卖是 **T+0 开盘买 → T+1 收盘**。  
不重训 106 维。

## 要挖的不是「再加三个因子」

别人的量化多半是收盘截面：涨停数、5 日净流入、缺口百分比。那些收盘才完整，上午买不到。

我们要的竞争力是 **09:25–09:35 能看见、别人盘后模型用不上的资金事实**，用来回答三句：

1. **这个板块现在是好的吗**（资金，不是涨幅榜）  
2. **里面已经起来的龙头还能不能跟**  
3. **里面还没涨、但钱已经在进的票，是不是更好的买点**

已有结论要对上，不要重做死胡同：

- 收盘「涨停助攻」有效，**盘中数涨停无效**  
- 早盘涨幅前 50 **是坑**（次日 −1%）  
- P2 买的是「还没启动」的票，9:35 低开组反而更好  
- 09:35 资金前 5 到 11:30 大半会换，**第 1 名更稳、还在加钱**

所以「助攻」要翻译成：**昨天板块资金 + 今天 09:35 板块资金龙头是否还在加**，不是数今天涨停。

## 这次能定下来的数

### 1. 连续净流入（生产名单上，样本够）

| 昨收前连续流入 | n | 当天开→收 | **开盘→次日收 T+1** | T+1 胜率 |
|----------------|---|-----------|---------------------|----------|
| 0 天 | 558 | −0.26% | **−0.55%** | 48% |
| 1 天 | 84 | +1.07% | **+2.46%** | 56% |
| **2 天** | 36 | +2.33% | **+4.09%** | **72%** |
| 3 天+ | 42 | +0.77% | +2.39% | 57% |

0 天和有流入是两种票。**2 天是甜区**，不是越长越好（3 天+ 变弱、左尾略肥）。  
这最适合做 09:35 **重排/否决**：连续 0 天往后退，2 天往前提。不要塞进 VM2.5。

### 2. 竞价缺口质量（同一生产名单）

| 开盘缺口 | T+1 |
|----------|-----|
| −2%～0% | **+2.57% / 胜率 63%** |
| 0～+2% | +1.65% |
| ≥+5% | 当天 −2.54% 回吐 |

「质量」= 温和缺口（平开到轻低开）+ 后面 P2 确认抬头，不是缺口越大越好。低开 −2% 已不踢池。

### 3. 热板块 × 龙头 / 待涨

生产历史分数文件一天往往只有 1～2 只，**没法在池内比龙头和落后股**。改成 2026-06 起全市场（23 万行 / 47 天）：

| 角色 | n | T+1 | 胜率 |
|------|---|-----|------|
| 热板块 + 龙头（5 日已涨） | 2745 | +0.37% | 51% |
| 热板块 + 落后 | 3510 | +0.15% | 45% |
| 热板块 + 5 日没涨 + 昨仍流入（待涨） | 1839 | **+0.48%** | 51% |
| 冷板块 + 落后 | 75524 | −0.08% | 48% |

方向对：**好板块里的待涨，略好于好板块里已经涨过的，也明显好于冷板块落后股。**  
但全市场等权很噪，左尾也更肥（待涨跌超 5% 占 22%）。不能单独当主策略，要叠在 **已经过模型+资金门的池子** 上，再加连续流入 1～2 天。

## 09:35 建议怎么用（还没写进生产排序）

```
候选池（05:00 分 + 资金门 + P2 下跌通道不买）
        │
        ├─ 否决：连续流入 0 天（除非盘中资金已翻红，下一轮再看）
        ├─ 加分：连续 1～2 天
        ├─ 加分：09:35 板块资金仍是当天前 1（或前 5 且相对 09:31 还在加）
        └─ 同类里优先：5 日还没涨、但昨天/今早资金已进的（待涨）
           而不是今早涨幅榜上的龙头
```

VM2.5 主分不动。这层只做更快的反应：别人用收盘涨停数，我们用上午还能看见的钱。
