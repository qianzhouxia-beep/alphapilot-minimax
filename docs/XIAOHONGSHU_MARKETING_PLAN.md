# AlphaPilot 小红书营销方案

## 一、平台定位与受众分析

### 小红书平台特征
- 月活 3 亿+，女性占比约 70%，但**财经/理财内容正在高速增长**
- 「理财」「搞钱」「副业」类目近一年搜索增长 200%+
- 用户偏好：**真实体验 > 硬广**、**可视化信息 > 纯文字**、**实用干货 > 概念说教**
- 爆款公式：利他性 + 情绪共鸣 + 视觉吸引力

### 目标受众分层

| 层级 | 画像 | 痛点 | 内容切入点 |
|------|------|------|-----------|
| L1 理财小白 | 25-35 岁，有稳定收入，想理财但不懂 | 「股票基金总是亏」「不知道怎么开始」 | 量化思维科普、防坑指南 |
| L2 进阶投资者 | 有交易经验，用过一些工具，效果不理想 | 「凭感觉买总是被套」「想系统化但不会」 | 量化方法论、工具对比、实盘思路 |
| L3 量化爱好者 | 了解 Python/策略，在摸索自己的系统 | 「回测漂亮实盘崩」「不知道怎么上线」 | 技术架构分享、在线自进化理念、工程化方案 |

### 内容调性
- **人设**：一个有 10 年经验的量化工程师，不卖课不推票，只分享真实的量化交易经验和系统设计思路
- **语气**：专业但不枯燥，坦诚但不炫技，偶尔幽默
- **视觉**：深色科技风为主，数据图表/流程图/KPI 卡片为视觉锚点

## 三、单篇内容模板

### 模板：专业干货型（以「在线自进化」为例）

```
【封面】
标题大字：「你的量化系统，真的在学习吗？」
背景：深色科技风 + 代码/GitHub commit 图
右下角小字：「AlphaPilot 量化笔记」

【正文】

你有没有想过一个问题：

绝大多数量化系统是「死的」。

因子权重写死在配置文件里，
止盈止损靠拍脑袋设阈值，
仓位分配永远是等权或固定比例。

市场风格一变——大盘切小盘、价值切成长——
你的「量化」就变成了反向指标。

因为它们不学习。
今天亏了 10 笔，明天还是用同一套参数开仓。

---

真正的机构是怎么做的？

城堡基金、Two Sigma 这些顶级量化机构，
有一个共同特征：自适应算法。

每一天的交易数据都在更新模型，
每一笔平仓都在优化下一次的预测。

这不是黑科技，这是工程化。

---

我做了一个开源的量化框架叫 AlphaPilot，
核心就是「在线增量学习」。

每次平仓 → 自动记录结果 → Online LR 更新 → 下次更准。
每天开盘，模型都比昨天多「见识」了一些。
```

## 四、视觉规范

### 封面图设计
- **主色调**：深蓝/黑底 `#0C1728` + 紫色渐变 `#7C5CFC → #8B5CF6`
- **字体**：字由 / 思源黑体 Bold，白色为主，紫色关键词高亮
- **最小元素**：量化风格网格/线条/代码片段/数据图表
- **格式**：3:4 竖版（1080×1440），文字集中在安全区域内

### 配图类型
| 类型 | 用途 | 制作方式 |
|------|------|---------|
| 代码截图 | 展示技术感 | VS Code + One Dark Pro 主题 |
| 流程图 | 解释架构/流程 | draw.io / Figma 深色模板 |
| 数据图表 | 实盘数据/对比 | Matplotlib 深色风格 |
| KPI 卡片 | 展示核心指标 | 前端组件截图 |
| 对比图 | 横向对比 | 左右分栏设计 |

### 排版规范
- **标题**：≤20 字，多用问句和数字
- **正文**：短句分段，每段≤3 行
- **重点**：**加粗** + 🔥 表情符号引导视线
- **标签**：每篇 5-8 个，覆盖品类词 + 长尾词

## 五、运营策略

### 发布节奏
- **首月**：每周 3 篇（一三五），建立内容密度
- **稳定期**：每周 2 篇（二四），质量优先
- **爆发期**：结合热点（如大盘暴跌、量化监管新闻）加推快讯

### 互动策略
- **评论区引导**：每篇结尾放一个开放性问题，前 30 分钟内回复所有评论（算法加权）
- **收藏夹**：创建 3 个公开收藏夹 —— 「量化入门」「量化进阶」「AlphaPilot 实录」
- **合集**：发布 ≥4 篇后创建合集「AlphaPilot 量化笔记」
- **直播**：月度一次「量化交易系统搭建答疑」直播

### 搜索优化（SEO）
**核心关键词池：**
- 量化交易 / 量化投资 / 量化策略
- Python 量化 / 自动交易 / 股票量化
- 仓位管理 / Kelly 公式 / 风险管理
- A 股量化 / 实盘交易 / 交易系统

**长尾布局：**
- 「为什么量化策略实盘跟回测不一样」
- 「散户怎么搭建自己的量化系统」
- 「最好的仓位管理方法是什么」
- 「量化交易需要多少资金起步」
