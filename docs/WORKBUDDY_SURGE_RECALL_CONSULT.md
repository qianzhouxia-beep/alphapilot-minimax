## 背景：主人在问什么

主人发现：**日频漏斗选出来的票不大涨；真正大涨的票经常选不出来。**  
怀疑门槛太多，而不是「最后 Top50 太少」。

已对齐的事实：

1. **启动形态命中数不固定**（全 A 日 K 扫描，命中多少算多少）。
2. **板块旁路不固定**（allow 行业成分，上限约 `HOT_SECTOR_MAX_N=600`）。
3. **VM 全 A 评分有效只数不固定**；`recommend.py` 只缓存 **评分 Top500**（`CACHE_N=500`）供后续门控。
4. **真正固定数量只在出口**：按 `position_exposure` → 池 `pool_n` = 0/10/50，下单 `top_n` = 0/1/2。
5. 管线顺序要点（`alphapilot_pipeline_v3.py`）：
   - 启动扫描 + 主线旁路  
   - `recommend.py` 全 A 评分 → 写 Top500  
   - **硬过滤：只保留「启动 ∪ 旁路」**；空了也**不回退全量**  
   - 资金门控 → 大盘环境 → **板块 dual 硬过滤** → 趋势等 → 截断 Top50/10  

主人倾向：**让流程自然漏下去，最后按分数取前 50（或 100）**，少用硬踢，提高大涨召回。

## Cursor 侧已提出的方案（请审阅）

### 目标定义（避免追涨停自欺）

- **要扫漏的**：次日仍有空间、且 **T+1 开盘买得到**、涨幅常 ≥3%/5%/7% 的票。  
- **不要当成成功的**：信号日已近涨停 / T+1 开盘一字——买不到，只记「识别到但不可成交」。  
- 验收对齐现有可交易协议：T+1 开 → T+2 收（或至少看 T+1 收），见 `docs/TRADABLE_V3_PLAYBOOK.md` / `docs/PIPELINE_V3.md`。

### 结构：双轨，而不是拆掉主臂

```text
全 A
 ├─ 主臂 A：启动 ∪ 旁路 → 偏硬门控（保胜率/回撤）
 └─ 扫漏臂 B：放宽入口 + 硬门改软分（保大涨召回）
        ↓
   合并去重 → 统一按分排序 → 自然截断 Top50（下单仍 Top1/2）
```

### 建议步骤

| 阶段 | 内容 |
|------|------|
| **P0 诊断** | 回放近 20–40 个交易日：当日/次日涨幅 ≥5% 的票，分别死在「未进 Top500 / 非宇宙 / 资金硬淘 / 板块 dual / 近涨停剔除」哪一层 |
| **P1 最小改动** | 评分 Top200 里因「非启动且非旁路」被丢掉的 → **软降权回流**，不再物理删除；对回流票 dual 改软扣分 |
| **P2 扩旁路** | 概念锋面 + 涨停密度高的行业进 B 池（与现有 `hot_sector_bypass` / `weak_rotation_sleeve` 思路衔接） |
| **P3 出口** | A+B 统一排序后固定取 Top50（薄仓仍 10）；池内标注 `arm=A\|B` |
| **P4 验收** | 样本外对比：主臂 Top2 vs 双轨 Top2；看 hit≥5%、成交率、maxDD；不过线回滚 |

### 硬门改软分（针对扫漏臂或回流票）

| 原规则 | 建议 |
|--------|------|
| 非启动∪旁路 → 删除 | 进 B / 回流，×0.85 之类降权 |
| 板块 dual 流出 → 删除 | 改为扣分；仅极端 deny 仍可删 |
| 资金 5 日极差硬淘 | 主臂可保留硬淘；B 臂改为大额扣分（明确出货除外） |
| 下跌通道硬踢 | **建议仍硬踢** |
| 近涨停不报 / 开盘涨停不成交 | **必须保留** |
| nuclear 空仓 | 扫漏臂同步清空或极度缩容 |

### 明确不主张的

- 只把出口从 Top50 改成 Top100（几乎解决不了漏大涨）。  
- 用 Wind 扫全市场个股资金（贵且与 B′ 策略冲突）。  
- 上线「宽松金叉 + 涨停延续」那类不可成交刷分臂（Playbook 已禁）。
