# Plan C vs Full Chain 卖出策略历史回测对比报告

> 生成日期: 2026-08-08
> 回测窗口: 2026-07-23 ~ 2026-08-07（12 个交易日）
> 样本: 120 个（每日 Top10 推荐 × 12 天，5 分钟线逐 bar 模拟）
> 方法: 同一批买入样本，两套卖出策略并行模拟，T+1 保护，扣双边费用 0.15%

## 一、总体结果

| 指标 | Plan C (qmt_model_plan_c.py) | Full Chain (qmt_model_full_chain_v1.py) |
|------|------|------|
| 毛收益均值 | 1.16% | 1.12% |
| 净收益均值（扣费） | 1.01% | 0.97% |
| 胜率 | 50.0% | 52.5% |
| 平均持仓 | 1.9 天 | 1.9 天 |
| 逐样本胜负 | 更好 50 (41.7%) | 更好 51 (42.5%) |

**总体结论：两套策略在样本期内收益几乎打平，但出场机制差异巨大。**

## 二、出场原因对比（差异核心）

| 出场原因 | Plan C | Full Chain |
|----------|--------|------------|
| T+1/T+2 尾盘强平 | 82 次 (68%) | 101 次 (84%) |
| 硬止损 | 20 次 (-5% 固定) | 11 次 (自适应，仅 14:45 后确认) |
| 跌停 | 1 次 | 9 次 |
| 移动止盈清仓 | 3 次 | 0 次 |
| 到期 | 11 次 | 10 次 |

**核心差异：**
1. **Plan C 的 `T1_FORCE`（68%）是"T+1 尾盘封单不强就卖"**，强制当天退出
2. **Full Chain 的 `T2_FORCE_AFTER_EXT`（84%）是"T+2 强平 + 可延期 1 天"**，留出更多观察时间
3. **Plan C 的 -5% 固定硬止损触发 20 次**，Full Chain 的自适应止损（约 -10% 且仅尾盘确认）仅触发 11 次

## 五、对"更合理方案"的建议

### 1. 固定 -5% 硬止损 → 调整为"阶梯式止损 + 尾盘确认"
- Plan C 的 -5% 固定盘中硬止损在波动大的票上容易被瞬间击穿误杀
- 建议：`-3% 半仓 + -7% 全仓`（放宽硬止损至 -7%，与 FC 自适应思想一致），且**硬止损仅在 14:45 后确认**（避开盘中假跌破），保留 -3% 半仓用于快速降风险
- 回测证据：Plan C 被 -5% 误杀的 2 个样本合计损失约 17% 利润，若止损放宽可挽回

### 2. 采用 FC 的"可延期 1 天"机制
- Plan C 的 T+1 尾盘强平过于激进（68% 当天就卖），对封单稍强但次日可能继续涨的票浪费机会
- 建议：吸收 FC 的 `t2_extended` 逻辑——`价格 >= 成本 × 0.95 时可延期 1 天`，让强票多跑一天
- 回测证据：FC 的 T2_FORCE_AFTER_EXT 占了 84%，且 Top2 子集收益更高（2.27% vs 1.82%）

### 3. 保留 Plan C 的封单率 + 开盘保护，但需真实 bidVol1 数据
- 回测中封单率用收盘封板近似（历史无 bidVol1），实际盘中 QMT 有真实封单数据，该逻辑在实盘更有价值
- 开盘保护（09:35-09:45 -7% 全卖）是 Plan C 独有优势，建议保留

### 4. 建议的组合方案（Plan C 骨架 + FC 灵活退出）
```
- 开盘保护：09:35-09:45 -7% 全卖          ← 来自 Plan C
- 阶梯止损：-3% 连续确认半仓，-7% 全仓      ← 放宽自 Plan C
- 硬止损确认：仅 14:45 后触发              ← 来自 FC
- 尾盘：封单强则持有，弱则卖；价格≥95% 成本可延期 1 天  ← 融合两者
- 移动止盈：arm≥3% + 回撤 1.5% 半仓        ← 两者相同
- Book A8/A4 提前退出                     ← 来自 Plan C
```

## 六、局限性

1. 样本仅 12 个交易日、120 个样本，覆盖一只短牛/震荡期，**不能代表全年**
2. 5 分钟线粒度下，"-3% 连续 3 分钟确认"用连续 bar 触及近似
3. 封单率用收盘封板近似，非真实盘口 bidVol1
4. 未考虑滑点、停牌、涨跌停无法成交等细节
5. 买入价用 09:35 开盘价，未完全模拟 GapSoft 择时
