# 工作台（Dashboard）板块解读与选股指南

> 适用页面：`https://alphapilot.api-tokenmaster.com/cn/`（工作台 / Dashboard）
> 更新日期：2026-08-11

---

## 一、页面总览

工作台采用**左固定侧栏 + 右侧主区**的两栏布局：

```
┌──────────────────────────────┬──────────────────────────────┐
│  左侧固定栏（侧栏）            │  右侧主区（内容）             │
│  ├ 评分 Top 10 · 09:35 定格   │  ├ KPI 指标卡（今日最佳等）   │
│  ├ 管线评分榜                  │  ├ A 股 Top 10 机会           │
│                              │  ├ 今日交易指令（A1 决策层）   │
│                              │  ├ 资金阶段分类                │
│                              │  └ 收藏追踪                   │
└──────────────────────────────┴──────────────────────────────┘
```

每个板块数据源不同、排序口径不同。下面逐个说明。

---

## 二、各板块的排列规则

### 1. 评分 Top 10 · 09:35 定格（侧栏第一位）

| 项目 | 说明 |
|---|---|
| **数据源** | `output/score_top10.json`（由 `scripts/build_score_top10.py` 在 09:35 终选后生成） |
| **池子** | 09:35 全市场终选候选（约 45 只），不足 10 只时从量价金叉池补评分 |
| **排序依据** | **三路融合综合分 `_fusion_weight` 降序** |
| **综合分公式** | `vm25 模型分 × 0.50 + 资金流 × 0.30 + 板块热度 × 0.20`（权重来自 IC 反馈 `model_weights.json` 动态调整） |

三个分项的含义：
- **模型分（vm25）**：VM2.5 模型概率，在池内做 min-max 归一化（0~1）
- **资金流（fund_flow）**：主力净流入做 tanh 归一化（+1 亿 ≈ 0.88）
- **板块热度（sector_heat）**：先按二级板块匹配今日主线板块（`hot_sector_bypass_pool.json`），再按一级板块匹配竞价热度（`call_auction_sector_heat.json`），未命中给 0.5

> 一句话：**这是"模型好 + 资金强 + 板块热"三个维度综合打分后的排名**，不设门槛，就是纯综合分前 10。

---

### 2. 管线评分榜（侧栏第二位）

| 项目 | 说明 |
|---|---|
| **数据源** | `output/daily_recommend.json`（每日管线全量输出，约 45 只） |
| **池子** | 09:35 终选通过的全量候选 |
| **排序依据** | **管线综合分 `score` 降序**（已含 05:00 模型分 + 板块资金 + 研报偏好等管线调整） |

- 显示完整排名（1~N），不截断、不设门槛
- 每行附带实时涨跌幅、盘中资金强度（强度分位 / 流速 / 冲板概率）

> 一句话：**这是管线内部打分的原始全量排名**，让你看到"今天选了什么、各排第几"。

---

### 3. A 股 Top 10 机会（主区）

| 项目 | 说明 |
|---|---|
| **数据源** | `/api/v1/cn/recommend`（读 `daily_recommend.json`） |
| **池子** | 09:35 终选后的综合分 Top 10 |
| **排序依据** | **与「评分 Top 10」同源**：读取 `score_top10.json` 的三路融合综合分降序前 10 |

- 这是主区最大的一块股票卡片区
- 卡片含：排名、代码、名称、所属板块、实时涨跌、评分、市盈率、主动买入占比、盘中资金强度等
- 顶部有 **PE 筛选（全部 / PE≤30 / PE>30）** 和 **趋势筛选（全部 / ↑上升 / ↓下跌）**
- 属于今日交易指令 Top2 的股票，卡片上会带 **「今日交易」** 绿色徽章（两个名单重合时才会出现）

> 一句话：**主区最核心的股票看板，与侧栏评分 Top 10 同名单**，方便对比查看详情。

---

### 4. 今日交易指令（主区，A1 决策层）

| 项目 | 说明 |
|---|---|
| **数据源** | `output/morning_live_picks.json`（09:35 `morning_live_fund_select.py` 终选） |
| **池子** | 09:35 全市场终选后资金门控通过的标的 |
| **选出数量** | **Top 2**（`trade_top_n = 2`） |
| **排序依据** | `money_flow_pass` 优先 → 按模型 `score` 降序（当前模式 `morning_live_model_top2`） |

- 这是**量化模拟盘实际下单的名单**，每天最多买 2 只，等权仓位
- 含参考买入价、目标仓比例、以及四层出场规则（动态止盈 peel / E2 硬止损 / T+2 强平 / 板块反转）
- 当状态为 `no_picks`（盘中资金重排后无候选）时，显示"无标的"

> 一句话：**这就是系统今天真正会买的 2 只**。

---

### 5. 资金阶段分类（主区）

| 项目 | 说明 |
|---|---|
| **数据源** | `/api/v1/cn/recommend/categorized`（读 `daily_recommend.json`，经 `categorize_by_phase` 分类） |
| **池子** | 09:35 终选候选 |
| **排序依据** | 每类内部按 `score` 降序 |

分 4 大板块：

| 板块 | 包含资金阶段 | 含义 |
|---|---|---|
| 🔴 **买入信号** | 拉升 / 右侧潜伏 / 吸筹末期 / 诱空陷阱 | 主力正在运作，关注买入机会 |
| 🔵 **吸筹观察** | 吸筹 | 主力在低位默默吸筹 |
| 🟠 **风险警告** | 诱多嫌疑 / 出货 | 警惕回调或出货风险 |
| ⚪ **暂时观望** | 回调 / 震荡 | 方向不明或回调中 |

> 一句话：**按主力资金运作阶段把候选分门别类**，帮你看清每只股票处在什么状态。

## 三、买股票到底看哪个推荐？

**结论：核心看「今日交易指令」，辅助看「评分 Top 10」和「A 股 Top 10 机会」。**

| 场景 | 看哪个 | 原因 |
|---|---|---|
| **我只想按系统信号买** | **今日交易指令** | 这是量化模拟盘真正下单的 Top2，与自动交易完全一致，最贴近"系统真实操作" |
| **我想自己从更强的池子里挑** | **评分 Top 10 / A 股 Top 10 机会** | 三路融合综合分（模型+资金+板块），覆盖面更广、更有信息量 |
| **我想知道系统今天整体选了哪些** | **管线评分榜** | 全量排名，看全貌 |
| **我想判断某只股票当前资金状态** | **资金阶段分类** | 快速定位"拉升 / 吸筹 / 出货"等阶段 |
| **我想盘中盯资金强度** | 任意卡片的**盘中资金**字段 | 强度分位、流速、冲板概率实时更新（每 3 分钟） |

### 推荐的完整决策流程

1. **每天 09:35 之后**，先看「今日交易指令」——如果状态是"可买入 / 半仓 / 轻仓"，那就是系统当天的操作信号
2. 再看「评分 Top 10」和「A 股 Top 10 机会」，了解综合分排名靠前的机会池（模型+资金+板块）
3. 结合「资金阶段分类」判断时机（买入信号 / 吸筹观察 优先，风险警告回避）
4. 盘中盯卡片的「盘中资金强度」，资金加速进场（流速 >1x、强度前 50%）可作为加分项

> ⚠️ 注意：**「评分 Top 10」是机会池（不设门槛），「今日交易指令」才是实际买入名单**。两者名单不一定重合（今日 Top2 可能不在综合分 Top10 内），因为排序口径不同——前者看三路融合，后者看模型分 + 资金门控。

## 四、常见口径补充

- **分数显示**：模型概率 0~1 会转成 0~100 分展示；原始综合分 >1 时用 sigmoid 映射到 0~100，便于直观比较
- **盘中资金强度**（卡片上"强度前 X% / 流速 Yx / 冲板 Z%"）来自 `institutional_watch.py` 每 3 分钟更新的 `fund_strength.json`
- **实时行情**：卡片价格、涨跌幅来自腾讯行情接口（`_attach_live_quotes`），交易时段 60 秒刷新
- **数据更新节奏**：05:00 管线初稿 → 09:25 集合竞价 → 09:35 全市场终选（生成 `score_top10.json` / `morning_live_picks.json`）→ 盘中 3 分钟资金强度刷新 → 15:30 EOD 全量更新
