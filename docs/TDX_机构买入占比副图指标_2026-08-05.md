# 通达信资金副图指标（机构买入占比版）

> 版本日期：2026-08-05
> 适用：通达信 PC 版（免费版 / Level-2 版均可）
> 用途：分时图盯盘时查看"机构买入占比"，>60% 提示主力强买，可能冲板

---

## 重要前提（先读）

**分档函数限制**：`L2_VOL` / `L2_AMO` 分档数据**仅支持日线及以上周期**，分时图无法调用。

**但分时有真 L2 函数**：`BUYVOL`（主动买量）/ `SELLVOL`（主动卖量）/ `ISBUYORDER` / `ISSELLORDER`（单笔是否主动买卖）**在分时周期可用**，前提是 **Level-2 行情数据已加载生效**（否则全部返回 0）。

判断方法：`SUM(BUYVOL,0)+SUM(SELLVOL,0)` 如果整天为 0，说明 L2 数据没加载——先用本文"五、L2 生效排查"确认。

- 无 L2 / L2 未生效：用下方"一、估算法"指标
- 已开通付费 L2 且生效：用下方"四、分时 L2 大单指标"（真大单数据）

## 一、分时副图指标（估算法，免费版）

### 功能
- 显示机构买入占比 / 机构卖出占比（当日累计）
- 机构买入占比 > 60% 时，K 线位置画红底黄字"机构强买"信号
- 机构净买入转正且加速时，画"拉升"信号

### 公式源码（新建指标公式，画线方法：副图）

```
成交额:=V*C/100;
机构买:SUM(IF(成交额/8>20 AND C>REF(C,1),成交额,0),0),COLORRED,LINETHICK4;
机构卖:SUM(IF(成交额/8>20 AND C<REF(C,1),成交额,0),0),COLORGREEN,LINETHICK4;
散户买:SUM(IF(成交额/8<20 AND C>REF(C,1),成交额,0),0),COLOR5555FF;
散户卖:SUM(IF(成交额/8<20 AND C<REF(C,1),成交额,0),0),COLOR55FF55;
总额:=机构买+机构卖+散户买+散户卖;
机构买占比:IF(总额>0,100*机构买/总额,0),NODRAW,COLORRED;
机构卖占比:IF(总额>0,100*机构卖/总额,0),NODRAW,COLORGREEN;
净占比:IF(总额>0,100*(机构买-机构卖)/总额,0),NODRAW,COLORYELLOW;
强势:100*机构买/总额>60;
拉升:100*机构买/总额-100*机构卖/总额>18 AND 100*机构买/总额-100*散户买/总额>18;
DRAWTEXT(强势 AND COUNT(强势,2)=1,机构买*1.02,'机构强买'),COLORRED;
STICKLINE(强势,机构买*1.02,机构买*1.1,1,0),COLORYELLOW;
STICKLINE(拉升,机构买*1.1,机构买*1.2,1,0),COLORFF00FF;
DRAWTEXT(ISLASTBAR=1,机构买*0.95,'●机构买'),LINETHICK2,COLORRED;
DRAWTEXT(ISLASTBAR=1,机构卖*0.95,'○机构卖'),LINETHICK2,COLORFFFF55;
```

### 使用方法
1. 打开通达信 → 功能 → 公式系统 → 公式管理器 → 新建
2. 公式名称：如 `机构买占比`
3. 画线方法选：**副图**
4. 粘贴源码 → 确定
5. 打开任意股票分时图 → 在副图位置右键 → 选择指标 → 找到该指标

### 信号解读
| 信号 | 含义 |
|------|------|
| 机构买占比 > 60% | 大单买盘占绝对主导，主力做多意愿强，冲板概率上升 |
| 机构净占比转正 + 拉升信号 | 主力从净卖出转为净买入且加速，短线拉升窗口 |
| 涨停后机构买占比 < 20% | 封板资金为散户主导，次日溢价可能有限，谨慎 |

## 二、日线级 L2 副图指标（真 L2 数据，需付费开通 Level-2）

### 功能
- 用真 L2 分档数据计算：超大单、大单、中单、小单的净买额
- 机构（超大单+大单）买卖占比

### 公式源码

```
机构买:L2_VOL(0,0)+L2_VOL(1,0),NODRAW,COLORRED;
机构卖:L2_VOL(0,1)+L2_VOL(1,1),NODRAW,COLORGREEN;
超大单净:L2_VOL(0,0)-L2_VOL(0,1),COLORRED;
大单净:L2_VOL(1,0)-L2_VOL(1,1),COLORMAGENTA;
中单净:L2_VOL(2,0)-L2_VOL(2,1),COLORLIGREEN;
小单净:L2_VOL(3,0)-L2_VOL(3,1),COLORLIBLUE;
主力净:超大单净+大单净,COLORYELLOW;
机构占比:100*(机构买)/(机构买+机构卖),NODRAW,COLORRED;
```

### 说明
- 该指标挂在**日线**周期副图使用
- `L2_VOL(0,0)` = 超大单买入量，`L2_VOL(0,1)` = 超大单卖出量（N:0-3=超大/大/中/小，M:0-1=买/卖）
- 需要通达信 Level-2 行情权限，否则返回无效值

## 三、最省事的方案（推荐）

如果你开通了 L2，分时图上**不用写任何公式**：
通达信自带 **"资金博弈"** 副图（分时图 → 右键 → 叠加指标 → 资金博弈），
它直接显示主力/散户的多空占比曲线，就是那些推送软件的功能来源。

## 四、分时 L2 大单指标（真 L2 数据，需 Level-2 已生效）

### 功能
- 主动买入 / 主动卖出占比（当日累计）——对应推送软件"机构购买百分比"
- 大单净额（单笔 ≥20 万主动买 − 主动卖，单位：万元）
- 主动买占比 > 60% 时画红柱 + "机构强买" 信号

### 公式源码（新建指标公式，画线方法：副图）

```
{分时L2大单 - 需Level-2行情已加载，否则全为0}
主动买量:SUM(BUYVOL,0),COLORRED,NODRAW;
主动卖量:SUM(SELLVOL,0),COLORGREEN,NODRAW;
总量:=主动买量+主动卖量;
主动买占比:IF(总量>0,100*主动买量/总量,0),COLORRED;
主动卖占比:IF(总量>0,100*主动卖量/总量,0),COLORGREEN;
净买占比:主动买占比-主动卖占比,COLORYELLOW;
大单买额:SUM(IF(ISBUYORDER AND AMOUNT>=200000,AMOUNT,0),0),NODRAW,COLORRED;
大单卖额:SUM(IF(ISSELLORDER AND AMOUNT>=200000,AMOUNT,0),0),NODRAW,COLORGREEN;
大单净额:(大单买额-大单卖额)/10000,COLORMAGENTA;
强买:主动买占比>60;
STICKLINE(强买,主动买占比,60,2,0),COLORRED;
DRAWTEXT(强买 AND COUNT(强买,2)=1,65,'机构强买>60%'),COLORFF00FF;
```

### 使用前提
- 必须在**分时图（1分钟）周期**挂载
- L2 数据已加载（先用第三节"L2 生效排查"验证）
- 若曲线整天为 0，说明 L2 数据没进入通达信

## 五、L2 生效排查清单（分时图看不到大单时逐项核对）

| # | 检查项 | 操作 |
|---|--------|------|
| 1 | **确认是 L2 版客户端** | 券商版需下载**带 L2 的完整版**（不是免费精简版）；官方版需购买并激活 L2 权限 |
| 2 | **重启通达信** | 开通 L2 后必须**完全退出再重新登录**，权限才加载 |
| 3 | **登录时勾选 L2** | 登录窗口/系统设置里找 "Level-2 行情" 勾选项 |
| 4 | **连接 L2 行情主站** | 行情→连接/行情主站，选择 L2 主站（非普通主站） |
| 5 | **分时图右上角看 L2 标** | 打开分时图，报价区/标题旁应有 **"L2"** 或 **"逐笔"** 标识 |
| 6 | **右侧明细是否"逐笔"** | 普通版右侧是 3 秒快照（一行多笔）；L2 版是**逐笔成交**（每笔有手数+买卖方向） |
| 7 | **资金博弈副图可叠加** | 分时图右键→叠加指标→资金博弈，能叠加说明 L2 数据在流入 |
| 8 | **自编指标检测** | 挂上方"四、分时 L2 大单指标"，若全为 0 → L2 未生效 |

### 最常踩的坑
- **开通了 L2 权限 ≠ 客户端已加载 L2 数据流**：很多券商开通后默认仍连普通主站，需手动切 L2 主站或重启。
- **手机版与电脑版 L2 分开计费**：手机开了不代表电脑能用，需在电脑端单独确认。
- **看的位置不对**：大单不在 K 线主图上，要看右侧**逐笔成交明细**、**资金博弈副图**，或挂自编 L2 指标。
