# AlphaPilot 模型全链路文案

> **一句话定位**：AlphaPilot 是一套「**预测模型选股 → 量化交易执行**」的全自动 A 股工作台，每天 05:00 全市场扫描、09:35 定格选股、盘中低吸买入、收盘自动复盘，全程模型驱动、数据闭环、风控兜底。

## 二、链路一：预测模型（选股引擎）

### 2.1 数据层：每一个因子都吃「真数据」

模型的全部输入均来自每日自动更新的数据仓，覆盖全市场 **4987+** 只股票：

| 数据 | 内容 | 更新时机 | 用途 |
|------|------|---------|------|
| K线全量 | 日K OHLCV + 复权（`kline_all.parquet`） | 每日 15:30 后 | 所有技术/量价/竞价因子的地基 |
| 集合竞价因子 | 竞价缺口、量能、强弱转换（`call_auction_factors`） | 从日K实时计算 | 竞价异动识别，无需 Level-2 |
| 基本面 | EPS/营收/净利/BPS/ROE/毛利率/PE/PB（`fundamental_data.json`） | 每日 16:50 | 估值与盈利质量 |
| 资金流历史 | 主力净额 1/5/10 日（`fund_flow_history.json`） | 每日 21:00 | 主力资金动向 |
| 筹码分布 | 90%成本集中度/获利盘/均价（`chip_data_all.json`） | 每日更新 | 持仓成本结构 |
| 龙虎榜 | 机构买入席位计数（`lhb_history.json`） | 每日更新 | 游资/机构动向 |
| 事件/业绩预告 | 预告类型与增幅（`event_forecast.json`） | 每日更新 | 业绩催化 |
| 融资融券 | 融资余额/融资买入（`margin_data.json`） | 每日更新 | 杠杆资金态度 |
| RD因子 | 10 个时序衍生因子（`extra_factors.parquet`） | 每日 21:20 重建 | 波动/趋势/资金交互 |
| 隔夜美股因子 | 美股隔夜表现 → A股情绪 | 05:00 前 | 隔夜环境温度 |

> 数据就绪保证：**每日 21:00-21:20** 资金流与 RD 因子先行重建 → 05:00 管线开跑前，全部数据拉齐且 100% 覆盖。

### 2.2 特征层：116 维因子全景

模型输入为 **116 维特征向量**，按作用分为 7 大板块。每个板块的**作用、数据来源、维度数**如下：

#### ① 核心技术因子（8 维）— 量价动能地基
| 因子 | 作用 | 数据 |
|------|------|------|
| ret_5d / ret_20d | 短中期动量 | K线收盘 |
| amount_ratio_5/20 | 成交额相对均量倍数（放量识别） | K线成交额 |
| vol_20d | 20日波动率 | K线收益 |
| vol_spike | 放量且涨幅温和（吸筹特征） | K线 |
| cmf_20 | Chaikin资金流（20日） | K线高低收 |
| vpt_20 | 量价趋势累积 | K线量价 |

#### ② 集合竞价因子（22 维）— 当天开盘情绪的「读心术」
从日 K 线的开盘行为反推竞价强弱，**无需 Level-2 也能捕捉竞价意图**：
- 缺口类：`gap_pct / gap_abs / gap_volume_ratio / gap_momentum / consecutive_gap`（缺口大小、量能、连续性）
- 确认类：`open_amt_ratio / gap_vol_confirm / volume_conviction`（开盘量是否确认）
- 强弱转换：`weak_to_strong / strong_to_weak / stronger`（竞价阶段多空反转）
- 风险类：`explosive_open / fake_gap / pump_exhaustion / fake_support / sector_collapse`（炸板、假突破、主力出货、板块崩塌）
- 综合：`bull_score / bear_score / composite / composite_z`（竞价多空总评分）

#### ③ 技术指标（13 维）— 经典派
`rsi_14`（超买超卖）、`macd/macd_signal/macd_hist`（趋势动能）、`bb_upper/lower/width`（布林带与带宽）、`sma_5/20/60`（均线）、`ma_dist_pct`（乖离率）、`atr_14/atr_pct`（真实波幅/波动占比）。

#### ④ 量价与波动结构（11 维）— 资金行为指纹
`turnover_ma_20 / turnover_ratio`（换手）、`vol_ma_ratio / amt_ma_ratio`（量比额比）、`vol_skew_20 / vol_kurt_20`（收益分布偏态峰度）、`up_down_vol_ratio`（涨跌波动不对称）、`price_vol_corr_20`（量价相关性）、`ret_range / ret_range_ma_20`（振幅）、`gap_pct`（跳空）。

#### ⑤ 技术信号（2 维）— 形态确认
`ma_cross_5_20 / ma_cross_20_60`（均线金叉信号）。

#### ⑥ 基本面 / 事件 / 资金 / 龙虎榜 / 融资（21 维）— 多维定价
| 板块 | 因子 | 作用 |
|------|------|------|
| 基本面(11) | eps/revenue/net_profit/bps/roe/pe/pb/profit_margin/revenue_yoy/net_profit_yoy/gross_margin | 估值与盈利质量 |
| 事件(3) | has_forecast / yjyg_max_change_pct / forecast_type | 业绩预告催化 |
| 资金流(3) | main_net_today / main_net_5d / main_net_10d | 主力净额短中长 |
| 龙虎榜(2) | buy_inst_count / has_lhb | 机构游资上榜 |
| 融资融券(2) | margin_balance / margin_buy | 杠杆资金态度 |

#### ⑦ 筹码因子（11 维，含衍生）— 持仓成本结构
`chip_concentration / chip_concentration_70`（90%/70%成本集中度）、`chip_profit_rate / chip_penetration`（获利盘/穿透率）、`avg_cost_shift_5d / avg_cost_shift_10d`（均价位移）、`z_chip_concentration`（集中度标准化）、`chip_profit_trend`（获利盘趋势）、`chip_distribution_width / shape`（分布宽窄与形态）。

#### ⑧ 衍生因子（8 维）— 因子间交叉
`volume_price`（量价叉乘）、`vol_turnover`（量×换手）、`money_flow_vol`（资金×量）、`momentum_accel`（动量加速度）、`trend_strength`（趋势强度）、`conv_div`（收敛/发散）、`price_dev`（价格偏离）、`bull_confirmation`（多头确认）。

#### ⑨ 技术优化因子（10 维）— 最优参数块
由回测搜索的最优均线/MACD 参数生成：`opt_ma_price_above_long / short_above_long / mid_above_vlong / long_slope / dist_long`（均线排列与斜率）、`opt_macd_dif / hist / hist_slope / dif_pos / zero_above5`（MACD 动能与持续性）。

#### ⑩ RD 因子（10 维）— 研发强化层
由 K线+筹码+资金流+基本面二次加工：`ret_range_ma_20__ma3/ma5/z20/diff3`（振幅多尺度）、`atr_pct__z20`（波动 z-score）、`turnover_x_atr_pct`（换手×波动交互）、`rd_auction_open_atr_ratio__ma5`（竞价强度平滑）、`profit_margin__ma5`（盈利平滑）、`ret_20d__z20`（动量 z-score）、`macd_hist__ma5`（动能平滑）。

### 2.3 模型层：XGBoost 三模型集成

| 项 | 配置 |
|----|------|
| 算法 | XGBoost（binary:logistic，AUC 评估） |
| 集成 | **3 个模型平均投票**（不同种子） |
| 训练样本 | 185 万+ 股票日（全市场时序） |
| 标签 | 未来 1 日收益 > +3% 为正样本（正样本率 11.1%） |
| 正负平衡 | scale_pos_weight=8.0 |
| 迭代 | 300 轮 / 早停 50 |
| 维度 | **116 维**（82 基础 + 8 衍生 + 6 筹码 + 10 技术优化 + 10 RD） |
| 验证 AUC | **0.7176**（三模型 0.6956 / 0.7469 / 0.7104） |

> 训练体系：滚动时序交叉验证 + A/B 对照（base vs opt）衡量每个模块的边际增益，技术块 +RD 因子边际增益 +0.0009。

### 2.4 融合层：三路信号加权（最终排名依据）

单一模型打分只是**原始模型分**。最终排名由三路信号融合（这就是"评分 Top10 · 09:35 定格"的真实逻辑）：

| 信号 | 含义 | 归一化 | 默认权重 |
|------|------|--------|---------|
| **VM2.5 模型分** | 116 维 XGBoost 输出 | min-max（池内归一化保区分度） | **50%** |
| **资金流** | 主力净流入 | tanh(main_net/1亿)，±1亿→0.24~0.88 | **30%** |
| **板块热度** | 板块当日涨幅/竞价热度 | clamp ±5% 线性映射 | **20%** |

**动态权重（反馈闭环）**：每日收盘后，用当日成交记录的「三路信号 vs 实际盈亏」算 Spearman IC，以 **EMA（α=0.10）** 滚动更新权重——哪一路预测力强，自动获得更多话语权，权重约束在 [0.05, 0.85] 并归一化到和为 1。

> 额外加权规则（研报 × 资金 × 竞价一致性）：
> - 集合竞价强势板块（09:15-09:35）→ **硬加权**（加分）
> - 研报回避板块 → **软惩罚**（降权而非剔除）
> - 研报 vs 资金主线 vs 竞价热度出现**冲突** → 额外 ×0.90 降权 + 预警

## 三、链路二：量化交易模型（执行引擎）

### 3.1 信号生成：四道门控（宁可空仓，不碰雷）

`paper_trading_signals.py` 每日 09:36 消费 Top2 信号，经 **四道门控** 后才可交易：

| 门控 | 作用 | 数据 |
|------|------|------|
| **情绪周期门控** | 大盘情绪阶段（冰点/亢奋）决定是否开新仓 | market_sentiment |
| **波动率门控** | 20 日波动率 > 3.5% 的高波动票拦截 | vol_gate |
| **硬过滤** | ST / 亏损 / 利空公告直接删除 | hard_filter |
| **多因子/Q1过滤** | 多因子打分，剔除最差 25% 分组 | multifactor_score |

> 任何一门拦截 → 该票不进信号；情绪拦截 → 当日不开新仓（nuclear 空仓）。

### 3.2 融合重排 + 仓位分配

1. **三路融合重排**：与选股同源的 `fusion_rerank`（VM2.5×50% + 资金×30% + 板块×20%），确保"推荐的就是要买的"。
2. **Kelly 仓位**：`KellyLearner` 每日在线重训逻辑回归，用 8 维特征（评分分位、波动率、仓位敞口、跳空、资金阶段、通道拒绝、板块热度、主力净额）预测**胜率**，反哺 `entry_weight`；Half-Kelly + 波动率调整 + 行业集中度约束，单笔上限 5 万。
3. **人工确认闸门**（默认开启）：出票先进 `pending_review`，网页确认后才写入买入信号。

### 3.3 买入执行：VWAP 低吸（不追高，等回踩）

放弃"信号价直接成交"，改为 **盘中回踩 VWAP 后以实时价成交**（`intraday_low.py`）：

| 参数 | 值 | 说明 |
|------|----|------|
| 触发条件 | 现价 ≤ VWAP×(1-0.8%) 且 现价 ≤ 昨收×1.03 | 回踩不追高 |
| 窗口 | 09:35 ~ 10:30 | 错过不强买 |
| 未触发策略 | abandon（默认，宁缺毋滥） | 10:00 后可 hybrid 放宽 ±1.5% |

> 回放验证（60 标的日）：**95% 能在盘中触发，触发价平均低于收盘价 3.16%**。成交价回写 `paper_trading.json`，前端展示真实成交价与 `entry_mode`。

### 3.4 出场执行：Plan C 分级风控

`trade_executor.py` 每 1 分钟扫描持仓，执行**分级出场**（与 QMT 实盘同源参数）：

| 规则 | 阈值 | 动作 |
|------|------|------|
| 分级止损 | -3% 连续 3 分钟 | 卖一半 |
| 硬止损 | -5% | 全卖 |
| 开盘保护 | 09:35-09:45 内 -7% | 全卖 |
| 跌停 | -9.5% | 立即全清 |
| **追踪止盈** | 创新高后从峰值回撤 6% | 全卖（让利润奔跑） |
| 涨停封单 | 买一/成交量 > 3 | 延期持有 |
| 超期清理 | 持有 ≥15 日 | 防呆清仓 |
| 异常保护 | 盈亏 > ±25%（疑似除权/数据错） | 不卖，等数据修复 |

**QMT 实盘版（`qmt_model_plan_c.py`）** 额外含：
- **封单比分级决策**（14:45 后）：封单>3 隔夜持 / 封单>1+低换手持 / 封单<0.5 次日卖（回测 5835 样本标定）
- **A8/A4 早离场增强**：昨高量+RSI≥80 或 高位大阴>6% → 触发概率 2.2~2.6 倍 → 直接减半不等回撤
- **主力行为 ML 信号**（5分钟，`qmt_model_02_主力行为ML_v3`）：33 维特征 + 600 棵决策树预测买卖/持有三态，纯分析不交易，辅助盯盘。

### 3.5 反馈闭环：交易 → 模型

```
每日成交 → kelly_learner_trades（含三路信号分 + pnl）
   │
   ▼ 16:15
fusion_scorer.update_ic_weights()
   │  Spearman IC（信号 vs 盈亏）× EMA(α=0.10)
   ▼
三路权重自动演化 → 次日选股排名用新权重
```

## 四、风险控制与安全机制（异常即停）

1. **P3 新鲜度闸门**：交易前校验 `health_alarm / daily_recommend / morning_live_picks` 新鲜度，任一过期 → **阻断交易**。
2. **评分质量门**：模型评分区分度/数量异常 → 标记 `daily_recommend`，当日不交易。
3. **数据真实性审计**：`data_quality_audit`（零填充率/覆盖率/双K线一致性）+ `pseudo_signal_detector`（资金流与价格背离/龙虎榜诱多/竞价诱多）+ `signal_conflict_detector`（研报×资金×竞价冲突）——盘中资金与研报冲突时**自动预警**。
4. **价格保护**：除权/数据异常（|盈亏|>25%）不卖；开盘前不撮合；午休不撮合。

> **AlphaPilot 的信念**：选股是概率问题，不是玄学。用 116 维特征还原市场的每一个切面，用三路融合对冲单一信号的风险，用 Kelly 控制每一次下注的尺度，用 Plan C 守住每一笔利润的底线——最终在数据、模型、风控三者之间，找到长期可复利的那个平衡点。
