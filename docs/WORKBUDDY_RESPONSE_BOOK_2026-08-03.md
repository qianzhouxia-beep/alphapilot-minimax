## 二、第二层：融合测试（关键，不能只看单测）

控制变量：同训练集，base(17维) vs base+7个书因子(24维)，3 窗口 walk-forward 严格 OOS。

| 窗口 | base AUC/IC | base+book AUC/IC | 差异 |
|------|------------|------------------|------|
| 1 (2025-12) | 0.7221 / 0.208 | 0.7226 / 0.208 | +0.0005 |
| 2 (2026-03) | 0.7124 / 0.229 | 0.7109 / 0.228 | -0.0015 |
| 3 (2026-06~07) | 0.6545 / 0.184 | 0.6557 / 0.185 | +0.0012 |
| **均值** | **0.6963 / 0.207** | **0.6964 / 0.207** | **+0.0001（噪声）** |

书因子特征重要性占比 11%（模型确实在用），但 **OOS AUC/IC 完全不动**。

**结论③（必须客观）**：即使单因子 IC 0.107 这么强，加进 XGB 依然零增益。原因：**XGB 从现有特征（ma20_dist/ret_10/vol 系）已学到等价信息**，书因子高度共线冗余。这是本项目第 6 次验证同一结论（v27 正则/v28 换手/逆势评分/资金流/open5m/跟庄书）——**日线信息 AUC 0.70 是天花板，单因子 IC 高 ≠ 模型增量**。

## 三、对文档 5 个待讨论问题的正式回复

1. **MA30 方向态做第一优先级？**
   → 分两半回答：做**训练特征：否**（融合验证无增量，已实测）；做 **pipeline 硬 Gate：是**（C 档 gate 是规则过滤，不受共线影响——这是它正确的用法，建议 `ma30_slope<0` 直接剔除/降权）。

2. **price_quantile_250 冗余？**
   → **是**。单测最强（IC 0.107）但融合零增益，正是"与现有特征共线"的实证。若坚持加，可与 ma20_dist 相关性核查后再定，但预期无增量。

3. **卖出信号因子接 QMT 跟踪止盈？**
   → **强烈推荐，这是 A 档真正的落地点**。A8（2.62x）/A4（2.20x）意味着持仓股若出现"高位大量+RSI80"或"高位大阴线"，**次日冲 3% 概率极高** → 可作 QMT 跟踪止盈的**提前离场/锁定利润增强**（冲高即卖，不等回撤）。优先级高于任何训练特征改动。

4. **洗盘-突破二段式接 09:35 重排？**
   → 逻辑合理（与 call_auction `fake` 因子衔接自然），但**无历史竞价数据，无法回测**——只能实盘积累验证。暂不建议作为开发重点。

5. **是否先跑因子单测？**
   → **已跑完**，结果见第一、二节。结论：单测有信号、融合无增量。

## 四、落地建议（按 ROI 排序，修正版）

1. **【最高 ROI，改 pipeline 不改模型】** C 档 Gate：MA30 方向向下 → 剔除；高位大阴线（>6% @ 高位）→ 剔除。规则过滤，立即可上线，不受模型天花板限制。
2. **【高 ROI，QMT 端】** A8/A4/A3 卖出信号 → QMT 跟踪止盈增强（冲高即卖）。
3. **【中 ROI，可选】** price_quantile_250 作为**二次重排**维度（Top50→Top2 时用），而非训练特征——避开共线问题，用它的排序能力。
4. **【不做】** 训练特征集不再加日线衍生因子（已 6 次验证无增量，浪费时间）。

## 五、对模型研究的总体判断（客观）

- **预测力已达标**：T+1 AUC 0.70 / Top5% 命中 2-3 倍，足够支撑"T+1 冲高止盈"假设。
- **瓶颈在交易执行层**：回测用收盘价判断止盈止损，与真实盘中挂单有系统性偏差（高波动股冲 3% 概率 12% 但回测锁不住）。
- **唯一真正的信息增量**是竞价因子（rd_auction，无历史无法回测）→ 实盘积累 + 09:25 后重评是唯一验证路径。
- **建议下一步**：① C 档 Gate 上线（规则，低风险）② A8/A4 接 QMT ③ 小仓位实盘验证 T+1 策略（盘中触发止盈的真实表现）。
