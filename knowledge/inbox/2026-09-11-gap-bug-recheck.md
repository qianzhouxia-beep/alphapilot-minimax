# 五分类 gap 基数 bug 复核（Cursor 独立复现）

WB 完成 P0-1（五分类生产口径重算）时报告：原研究除"买晚一天"外，**gap 的分母也错了一天**。
Cursor 用服务器 K 线 + WB 逐笔明细**独立复算**，三项全部证实。

## 一、gap 基数 bug —— 证实
穷举 (分子字段×偏移, 分母字段×偏移) 复现存档 `gap`（130 笔主窗口）：

| 公式 | 命中/可比 |
|---|---|
| **`open(+1)/close(−1)−1`** | **124/127 (97.6%)** ✅ |
| `open(+1)/close(0)−1`（正确） | 1/127 ❌ |
| 次优 | 7/127 |

**更锋利的刻画**：存档 `gap = close(D−1) → open(D+1)` = **D 日全天收益 + D+1 隔夜跳空**。
它根本不是"跳空"，而是**跨两天的收益**。⇒ 上涨段里 D 日自身涨幅被灌进 gap，**所有"平开"被顶成"高开"**，故原文"平开走高 0 笔"是该 bug 的直接产物。

## 二、t0/t1 语义 —— 坐实 `date = 选股日 D`
| 字段 | 公式 | 命中 |
|---|---|---|
| `t0` | `close(D+1)/open(D+1)−1` | 264/267 |
| `t1` | `close(D+2)/open(D+1)−1` | 253/257 |

⇒ 原研究口径 = **D+1 开盘买**（非生产 D 09:36）。

## 三、统计结论 —— 逐项复现（267 笔 / prod_main 127 + prod_exp 140）
| 检验 | 值 |
|---|---|
| 走高（按天聚类） | 27 日 **+3.77% / t=6.88** |
| 走低（按天聚类） | 24 日 **−1.76% / t=−3.83** |
| 同日配对（走高−走低） | 24 日 **+5.46% / t=9.93** |
| 晚一天入场成本 | **+1.27%/笔 / t=2.83** |

分类（合并 267）：高开走低 19.9%/−2.21%/胜 26.4%；高开走高 23.6%/+4.12%/胜 76.2%；低开走高 23.2%/+4.73%/胜 79.0%。
**"低开 > 高开"改写复现**（低开聚类 +2.12% t=3.22 vs 高开 +1.72% t=1.72）。

**判定**：本项目**第一个扛住"逐笔 t + 按天聚类 t + 同日配对 t"三件套的分组结论**。对照板块 streak（聚类后 0.98）——同纪律下，一个砍假、一个保真。**G1 证据基础因此变强，靶子体量从"近半"缩到约 1/5~1/3。**

## 九、交易端口径重跑："走高侧超额消失"是**误用侧端出场**的假象（2026-09-11 晚）

### 链路：用户澄清"交易端在哪"
用户定调：**选股端 = 服务器；交易端 = 本地 `production_strategies/track_a` + `track_b` 的 live/sim**（看 QMT 买卖逻辑查本地，不查服务器）。
⇒ 此前把**服务器 `trade_executor.py`（选股端自带纸面模拟）**当"生产真实出场"是**归属错误**。

### 用交易端规则重跑同一 263 笔（peel 仅核心近似）
交易端 Track A 出场核心：`arm +3% → 峰值回撤 pb 卖半 → 最多 2 刀清 → 硬止损 −10% / 跌停 −9.7%`。
- **live v2.38**：首触即卖，`pb = min(0.05, 0.015+dev*0.03)`（默认 1.5%）
- **sim v2.45**：次 bar 确认，`pb = min(0.02, …)`

| 出场 | 全体 | 胜率 | 走高(聚类)t | 走低(聚类)t | 同日配对 t |

| 持到 D+1 收 | +0.55% | 49.4% | 3.41 | −3.03 | 5.66 |

### 结论（重要，修正 §八/§②）
1. **用交易端真实出场，"走高"侧仍显著为正**（t 3.2~5.1），且全体为正（+0.3~+0.8%）。
2. ⇒ §八 "真价+plan_C = −0.21%、走高 t=0.59" 与 §② 的"可交易超额消失"，**是误用服务器侧端纸面出场造成的**；**应按交易端口径修正**。

4. ⚠️ **本重跑是 peel-核心近似**（未含 Track A 的 day-VWAP 破位、Wyckoff BC、T+2 强制、弱市 floor、loud_vol 等）。要定论须**用完整 Track A 在真实 5m/日内数据上做一次正式 replay**。

### 纪律
**谈"生产出场"必须点名：轨道 A/B × live/sim × 版本。** 服务器 `trade_executor.py` 只能叫"选股端纸面模拟"。

**三条**：
