# 存活因子族：组合级增量检验（两个样本）

## 问题

全市场 IC triage（`2026-09-10-factor-triage-full-market.md`）筛出**低活跃/低波动族**在全市场右侧条件下稳健
（`atr14 ret_std20 box20 turnover vol_5_20 vr20 ar20 amp shrink_days vr5 ar5`）。
但 **IC ≠ 赚钱**：一批因子的 IC 符号虽稳，组合级增量在候选池小样本上并不稳。
本卡回答三件事：

1. 这个族**加在 gene 之上**能不能提高组合收益（用真实出场口径）？
2. 方向是**低波动/低活跃**（fwd5 IC 方向）还是**高波动**（`hit3_t1` 摸 +3% 方向）赢？
3. 有没有**单个因子**在两个半段都为正、且增量有经济意义？还是只是多重检验噪音？

## 方法

脚本 `bt_research/bt_survivor_portfolio.py`（服务器 `/home/ubuntu/alphapilot/bt_research/`）。
全部因子 **T-1 收盘时点**（无前视），定义与 `bt_factor_triage.py` **完全一致**。组合机制对所有变体**完全相同**。

### 样本 A（主，高功效）：合成全市场组合，19 个月，日频出场代理

- **池**（信号日 s = T-1 收盘）：右侧 `close>MA20 且 MA20_slope5>0`、`amount>=1e8`、`close>=2`、`vol>0`、
  且 `ret1 < 9.5%`（T-1 未接近涨停）。结果 **506,399 行 / 4,976 只 / 384 个信号日 / 385 个交易日**，剔除 ST 用不了名字（面板无 name 列）。
- **基线**：gene 代理 = 逐日池内 rank 和（`ret10` + `MA25_slope5` + 10 日涨停次数），取 **Top2**。
- **入场**：T 开盘（P2 成交的日频代理）。
- **出场（主口径，对所有变体一致）**：T+1..T+3，若 `low<=entry*0.96` → −4%（**止损优先**），否则若 `high>=entry*1.03` → +3% 锁盈；
  都没触发 → T+3 收盘。**日内路径不可知**，`stop-before-target` 是假设，日线 OHLC 无法还原盘中先后。
- **组合**：最多持 4 只、每日最多买 2 只、每只 15% 净值、日频 MTM、无杠杆。
- **变体**：`F_filter`（按符号对齐后的因子剔除最差四分位，保持 gene 排序取 Top2）；
  `B_blend`（gene Top5 内按 `-rank_pct + 0.5*factor_z` 取 Top2）。低活跃方向 11 个 + 高波动方向 4 个 +
  最正交子集 `ORTHO_combo`（`vr5/ar5/vr20/ar20/shrink_days/vol_5_20` 的符号对齐 rank 均值）+ `dma20` 对照，共 34 个变体。
- **敏感出场**：`nostop`（去掉 −4% 止损）、`c1`（T+1 收盘）。
- **半段**：cut = **2025-11-26**；增量必须在**两个半段都 > 基线**才算 `BOTH=YES`。

### 样本 B（确证，真实出场）：真实候选池 + 5m `abs3_trail`

- 复用 `bt_exit_schemes.py` 的候选构造：`output/daily_picks_archive/*/top10_ungated.json`，
  入场 = T 09:40 5m 开盘，出场 = T+1..T+3 的**真实 `abs3_trail`（+3% 武装 / −4% 止损）**。
- 因子同样取 **T-1 收盘**。可用 **263 笔候选 / 27 个交易日**；组合只成交 **54 笔**（每日 Top2、最多持 4）。
- n 极小，**只作方向性参考**。

## 判定（正面回答三个问题）

1. **是否加在 gene 之上？** 在**高功效样本 A** 里，只有 **`F_filter`（剔除最差四分位）在低活跃方向**有小幅、两半同为增量的效果：`turnover`（全期 +12.3pp；H1 +8.8 / H2 +9.0）、`box20`（+5.4/+5.8）、`atr14`（+5.2/+2.0）。**blend 全部更差**。但在**真实候选池样本 B** 里，低活跃 `F_filter` 基本不加分（`shrink_days` 最差），加分的是 **blend**（turnover/vol_5_20/高波动）——两样本的"哪种集成方式有效"**互相矛盾**。
2. **哪个方向赢？** **在样本 A 主口径下是低波动/低活跃方向**（triage 的 fwd5 方向）；**高波动方向（`hit3_t1` 摸 +3% 方向）在组合层几乎不产生增量**（filter ≈ 基线，blend 更差）——即"波动大更易摸 +3%"**不能转化为组合增量**，因为其下行对称性吃掉了锁盈收益。**但**：低活跃的加分**换成 T+1 收盘出场即全部反转**（c1 口径 0 个 BOTH），说明它不是稳定的 alpha，而是"非对称赔付 + 剔除过度延展"的产物。样本 B 甚至偏向高波动 blend。
3. **单因子？多重检验？** 唯一在 A 的**主口径 + nostop 两种出场下都两半为正**的是 **`turnover`（换手率，低换手优先）**（main +8.8/+9.0，nostop +40.2/+19.5），第二是 `box20`。但：
   - 34 个变体里 **5 个** BOTH=YES；若增量为随机符号，期望约 **8.5 个**（P≈0.25）。**观测到的 5 个比随机还少** → 单靠"两半同正"**无法拒绝"纯噪音"**。
   - `turnover`/`box20`/`atr14` 高度相关（同属"低活跃"风格，geneIC 0.5~0.74），本质是**一个假设**；`turnover` 在 B 中只有 blend 才行。
   - 同时 `dma20` 对照（已知无效的"防追高"）在主口径也 BOTH=YES（+2.6/+0.1）→ **该判据本身偏松**。
   
   **结论：没有任何单个因子达到"稳健 + 经济显著"的双重门槛。诚实的答案是——这一族在组合层没有可靠的增量。**

## 关键警告（勿混）

- **样本 A 绝对收益是负的（基线 −58%/19 个月）**。这是**日频出场代理**的结构性偏差：`stop-before-target` 假设把"同一天既摸 +3% 又摸 −4%"一律判成 −4%，且日频代理**丢掉了真实 `abs3_trail` "冲高后继续持有"的上行**。+3%/−4% 赔付下胜率须 >57% 才不亏，基线 46% → 机械亏损。**因此样本 A 只能看"相对增量"，不能看绝对盈亏**；样本 B（5m 真实出场）基线是正的（+4.67%）。
- **合成池 ≠ 真实模型选股**。基线 = gene 代理 Top2 = **最延展的右侧动量票**；triage 已证明 `ret10/slope` 类**负 IC**，所以基线本身就是"逆 fwd5"的差组合，且**亏损严重**。低活跃 filter 的"加分"很大程度只是**少买最延展的名字**（`dma20` 对照同样 YES 即为证据）——这与候选池上"加新鲜度重排不赚钱"的旧结论并不矛盾，而是同一现象的另一面。
- **换出场即翻**：低活跃方向在 `c1` 口径下全部大幅跑输（`box20` −69/−121）。**方向不是因子性质，是赔付函数的性质。**
- **样本 B 只有 27 个交易日 / 54 笔**，H2 ≈ 9 天；且 5m 只有 high/low，**看不到 bar 内路径**（同根既碰止损又碰 trigger 统一按止损优先），未计滑点/手续费。**方向性参考，不作结论。**
- **多重检验**：34 变体 × 3 出场；"两半同正"观测 5 个 < 随机期望 ~8.5 个 → **不能声称显著**。
- **低波动/低活跃可能是小市值/低流动性代理**（未做市值/行业中性；虽 LIQUID 视图在 triage 中几乎不变，部分缓解）。
- 未改任何生产/模拟代码，未碰 `production_strategies/`，未部署。

## 可落地含义

- ❌ **不建议**把该族的任何 filter/blend 直接接入选股（证据不足以支持，且方向随出场/样本翻转）。
- ✅ 唯一值得登记为**观察项**的是 **`turnover`（低换手优先）**：在最高功效样本的主口径与 nostop 口径下两半都为正，且 `turnover` 是 triage 中强度高、两半稳健的因子。但要等**真实候选池 ≥90~120 个交易日**再做一次组合级两半检验，再谈落地。
- ⚠️ 更根本的杠杆仍是**重设 gene / 真实 rank 本身**（而非在其上叠加因子），与本轮结论一致。
