# 港股/美股纸盘设计方案（2026-09-09，待拍板 v0.1）

## 背景与约束
- 用户住深圳近香港，拟香港开户，**优先港股、其次美股**，要求"先跑模拟盘"。
- 可复用 AlphaPilot 的**流程资产**（特征工程→打分→排序→闸门→执行→IC反馈→重训 + 数据可靠性 L1-L6 纪律）；**信号资产大部分不可迁移**（见下）。
- 刚经历教训：A股 signal 原样搬去 crypto = -7% 冻结（2026-09-08）；美股更机构化，A股"散户结构 edge"只会更弱。

## 可迁移 vs 需重建
| 资产 | 港股 | 美股 | 处置 |
|---|---|---|---|
| 动量/趋势(TrendState思路)/市场环境 | ✅ | ✅ | 直接搬框架重训 |
| 量价/波动/均线族 技术因子 | ✅ | ✅ | 直接搬 |
| 106维 V25 模型本体 | ❌(训练域A股) | ❌ | **不迁移**，新市场新训小模型 |
| 涨停/连板/竞价 | ❌无 | ❌无 | 砍掉 |
| 筹码分布 | ❌无此口径 | ❌无 | 砍掉 |
| 主力资金流(东财) | ⚠️ 换**南向资金**(港股通) | ❌ | 港股=南向最像现有逻辑 |
| T+1/涨跌停节奏 | ❌ T+0 | ❌ T+0 | 买卖模型重写(无竞价门/P2确认概念) |
| 执行层 QMT/TDX | ❌ | ❌ | 换券商API或自建 |
| 印花税/费用 | 港股印花税0.1%双边+佣金 | 美股无印花税 | 纸盘按真实费率扣 |

## 分阶段方案
### Phase 0 数据与标的池（~1周，先行）
- 验 gtimg US(usAAPL) 报价/日K、HK 全池代码表来源；港股通标的 ~500 + 流动性过滤(成交额/市值) 作为候选池。
- 日K落地新加坡（cron 盘后，仿 A股 kline 缓存）；南向资金(港股通)日级落地。
- 数据可靠性 L1-L6 直接套用（数据契约/readiness/告警），第一天就立闸。

### Phase 1 信号与打分（MVP 用透明因子，不先上 ML）
- HK 首版组合 = 动量(3/6/12月) + 趋势结构 + 波动/回撤 + 质量(ROE/负债) + **南向资金流**；日频换手低频(日/周)起。
- US 首版 = 动量 + 质量 + 低波 + (可选)盈利漂移。因子方向/权重先用透明加权跑出基线，有 IC 积累再谈模型。
- 先做**研究仓**：因子IC/分层回测在 bt_research 同款纪律下跑，不碰生产。

### Phase 2 纸盘引擎（自建，跑起来的目标）
- **在 falun新加坡**建轻量纸盘：仿 crypto paper_trader 结构（ledger/position/halt闸/guardrail 全复用），无 A股竞价门，改 **T+0 日内规则**；日K选股 + 盘中(实时报价)择时两段。
- 费用按真实：港股印花税 0.1%×2 + 佣金 + 平台费；美股 SEC费/佣金。
- **不接真实券商 API 也能先跑**（行情=腾讯源，成交=自模拟）。账户开了之后可选接券商沙盒（富途/老虎 sandbox）做"接线测试"，再谈实盘。

### Phase 3 反馈闭环
- IC 追踪 + 成交留痕 + 每周健康报告（全部沿用 A股那套 infra，脚本改数据源即可）。

### Phase 4 实盘路径（后话，先不做）
- 港股：富途 OpenD 或老虎 API（沙盒先行）→ 小额实盘；美股：Alpaca/IBKR。
- 风控先行：单标的/行业/总仓上限、日回撤熔断——吸取 crypto 裸奔教训。

## 分工建议
- Cursor(Mac)：数据管线/因子/纸盘引擎/闸门（本次核心交付）。
- WB：可认领港股南向资金研究/因子 IC 验证（其 token 修好后）。
- 用户：开户决策、费率确认、每日一眼 readiness。

## 风险
- 港美股无涨跌停/筹码/主力资金，edge 需重挖（crypto 是前车之鉴）→ 纸盘至少跑 1-2 个月看 IC/回撤再谈钱。
- 数据：腾讯源免费但有风控可能 → 已纳入 L3 多源思维(备：akshare港/新浪)。
- 合规：香港开户/跨境投资资格、税务(wash sale 等)由用户自核，不属技术域。
