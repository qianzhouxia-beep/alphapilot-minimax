# 门控/因子落地规格书 G1/G2（E25/E26 → 执行层）

- 作者：WB-Mac，2026-09-15。依据：E25（隔夜美股 AI → A 股 AI 篮子，gap corr 0.49）、E26（9/17 类决议缺口日）。
- 性质：**规格即工单**。G1/G2 当前均为 **shadow 记录态**（只打标不拦截），启用硬门控须先过第 5 节验收协议。
- 数据前置：`deliver/ingest_us_daily.py`（新浪美股日线，E25 实测可用）。

## 1. G1 — overnight_us_ai_gate（隔夜美股 AI 门控）

**输入**：`us_daily/overnight_signal.json`（ingest 模块输出），字段：
```json
{"cn_date":"2026-09-15","us_date":"2026-09-14","nvda_ret":-0.0336,"qqq_ret":-0.008,"g1_flag":"ai_rebound_watch"}
```

**规则**（阈值与 E25 样本五分位对齐，改动须同步 `deliver/ingest_us_daily.py` 头部常量）：

| 条件 | flag | shadow 行为（v1） |
|---|---|---|
| NVDA 隔夜 ≥ +2.9% | `ai_chase_guard` | 当日 AI 类池票在网页标注；`research_gate` 日志记录"追高风险日"；**不拦截** |
| NVDA 隔夜 ≤ −3.1% | `ai_rebound_watch` | 记录"低开修复观察日"；**不自动买** |
| 其余 | `none` | 无动作 |

**AI 票的判定**：v1 用手工篮子（20 只，见 `bt_ab_local/e25_us_ai_overnight.py`）——已被 E25g 证明入池率过低（21 天仅 5 只次）。**硬门控启用前必须完成行业映射数据基建**（工单③），把 AI 定义换成板块成分（东财/申万分类）。

**消费点**：09:00 读取信号 → 09:35 live 重排 / 09:36 打单前可用（J14 ✓）。若未来要条件化 05:00 隔夜池重算，需另加 04:40 早班 fetch（夏令时可行、冬令时不可行，二期再议）。

## 2. G2 — gap_day_flag（重大事件缺口日风控）

**输入**：`knowledge/ops/event_calendar.json`（人工维护，Cursor 挂到服务器；格式 `{"date":"2026-09-17","events":[{"name":"Fed FOMC","time_bj":"02:00","weight":"high"}]}`）。

**行为**（v1 shadow）：weight=high 的事件日（决议次日=缺口日），09:36 打单前输出提示：
- **不追缺口方向**（E25：外部信息一步定价在开盘缺口、盘中反号，分半窗稳定）；
- 记录当日缺口幅度与盘中表现（自然实验，自动累积 G2 验收数据）。

**红线**：G2 永远是提示不是信号——"等确定性信号再动"属不可证伪句式（J11），不进决策链。

## 3. 数据流（目标态）

```
04:00-05:00 北京时间  美股收盘
05:30  ingest_us_daily.py（只读采集，落 us_daily/）        ← 需老板逐次授权后由 Cursor 挂

09:35  live 重排（G1 flag 仅透传网页+日志，v1 不改排序）
09:36  打单前：G2 提示（若有事件）
```

## 5. G1 验收协议（启用硬门控的唯一路径，J13）

1. shadow 期 ≥ 60 个交易日，期间自动记录每个 gated 日的：池内 AI 票（行业映射口径）09:36→收盘超额、对照非 gated 日；
2. gated 日样本 ≥ 10 个；
3. 方向复验与 E25 一致（chase_guard 日 AI 票盘中超额 < 0 且 t ≤ −2）；
4. 三条全过 → 提交老板知情后，由 Cursor 把 G1 从 shadow 升级为 research_gate 内的真实门控。

## 7. v1.1 更新（2026-09-16 Cursor）— overnight_signal 前滚缺陷修复

**事故**：`cn=2026-09-16` 行拿到 `us=2026-09-14` 的陈旧值（与上一条一字不差）。根因两层：

1. **上游发布延迟（不是 ingest 失败）**：09-16 05:30 ingest 日志 `all ok`，但新浪日线当时最新只到
   09-14。美市 09-15 收盘 = 北京 09-16 04:00，05:30（+1.5h）该 bar 尚未发布；当晚 23:51 已可见。
2. **前滚逻辑静默复用（真缺陷）**：`prev_us_session` 回扫 5 天取"最近可得"，预期 09-15 缺失时
   静默复用 09-14 ⇒ 新 cn 日期携带陈旧外盘值，且无任何标注。

**修复（`scripts/ingest_us_daily.py` v1.1）**：

- 新增美股日历 `US_MARKET_HOLIDAYS`（2025–2027）+ `expected_us_session(cn)`：唯一允许的美市日 =
  严格早于 cn 的最近**交易日**；周末/假日自动跳过（保留日历补齐语义）。
- 预期美市日缺失 ⇒ 显式 `us_date=<预期>, nvda_ret=null, qqq_ret=null, g1_flag="stale",
  stale_reason="expected_us_session_not_ingested"`，**绝不前滚**。
- 05:30 运行时若预期缺失，日志打 `WARN … -> row marked stale (no forward-roll)`。
- `<out_dir>/backfill_notes.json`：人工订正行持久标注 `backfilled=true` + `backfill_note`（跨次
  重生成保留）。单测 `bt_research/_ut_us_overnight_signal.py` 15/15。

**回填（已完成）**：`cn=2026-09-16` 重算为 `us=2026-09-15`（NVDA **+0.5736%** / QQQ **−0.6543%**），
`g1_flag` 由错误的 `ai_rebound_watch` 订正为 **`none`**，带 `backfilled=true`；同日 g1 研究门账本与
candidates 标注同步订正（仅标注，无重排）。

**调度**：05:30 主跑之外新增 **07:00 / 09:20 兜底重跑**（`run_us_ingest_daily.sh`，幂等；09:20 在
09:38 G1 stamp 之前）。`run_us_ingest_daily.sh` 改为 ingest 非零退出也照常 stamp+mirror，末尾透传 rc
（避免上游部分失败时镜像冻结）。

**红线**：若新浪日线在次日 09:20 前仍不发布，`cn` 行会是**显式 stale（空值）**——刻意的"缺行优于
错值"。本轮**不新增数据源、不改 G1 阈值**；是否加"实时报价补充源"由老板拍板。
